## Decisions Made

- **icon-lucide -> inline SVG:** The source project used a CDN icon font (icon-lucide) which violates CSP. Two usages converted: the copy button icon (Lucide "copy" icon SVG) and the server carousel icons (globe, chat-bubble, bar-chart SVGs). The `ServerInfo` interface was updated to use `icon: React.ReactNode` instead of `iconCode: string`.
- **div not main for page:** Source project used `<main>` but our global CSS may apply max-width to `main`. Using `<div className={styles.page}>` is safer and avoids unintended width constraints.
- **Server component for page.tsx:** The page itself has no hooks — HeroSection, FeaturesSection, and ContactSection each declare `'use client'` and manage their own state. The page is a clean server component.
- **Click-to-copy wired:** The old page.tsx had the copy logic but ContactSection.tsx used icon-lucide. Now ContactSection.tsx owns the copy button with navigator.clipboard.writeText and textarea fallback.
