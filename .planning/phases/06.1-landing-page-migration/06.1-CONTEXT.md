# Phase 06.1: Landing Page Migration - Context

**Gathered:** 2026-03-22
**Status:** Ready for planning

<domain>
## Phase Boundary

Migrate the home page from D:\AI Playground\ImportPecilToCode into this project, replacing the existing landing page. Organize components into the project's feature-grouped structure, integrate the design token system, wire auth context into the NavBar, and connect nav items to existing routes. Only the home page is in scope — no other pages from the source project.

</domain>

<decisions>
## Implementation Decisions

### Component Organization
- **D-01:** Landing-specific sections (HeroSection, FeaturesSection, ContactSection) go to `components/features/landing/components/`
- **D-02:** NavBar + Logo + GearIcon go to `components/globals/layout/` — these are global navigation, not landing-specific
- **D-03:** NavBar replaces the existing Header component entirely. Delete old Header + Header.module.css. Update all layouts that import Header.
- **D-04:** CSS module files travel with their components (e.g., HeroSection.module.css stays next to HeroSection.tsx)

### CSS Token Integration
- **D-05:** Import source `tokens.css` as-is into globals.css (`@import './tokens.css'`). Keep as separate file.
- **D-06:** Landing components keep their CSS module approach (no Tailwind). Tailwind is only used with HeroUI components.
- **D-07:** Existing globals.css variables stay — no conflict. Globals will eventually be replaced by the frontend milestone.

### Auth Wiring
- **D-08:** Wire `useAuthContext()` into the new NavBar. Show logged-in state (avatar + username) when authenticated, show LOG IN / guest login buttons when not.
- **D-09:** Reuse existing auth patterns from `components/features/auth/` — LoginForm, AuthProvider, useAuth hook.

### NavBar Routing
- **D-10:** Wire nav items to existing routes: COST TABLES -> /costs, TEAM BUILDER -> /teambuilder, LOBBIES -> /lobby
- **D-11:** TOURNAMENTS and EVENTS remain as non-functional placeholder buttons (no routes exist yet)
- **D-12:** Nav item click navigates via Next.js Link, not button state toggle

### Assets
- **D-13:** Copy video asset `public/recording/topaz-loop-animation2.mov` to this project's `public/recording/`
- **D-14:** HeroSection video path stays as `/recording/topaz-loop-animation2.mov`

### Page Structure
- **D-15:** Landing page at `app/(landing-page)/page.tsx` — replace current content with NavBar + HeroSection + FeaturesSection + ContactSection
- **D-16:** Landing layout at `app/(landing-page)/layout.tsx` — update to use new NavBar instead of old Header, remove Footer if not in new design
- **D-17:** Existing sub-routes (/costs, /teambuilder) stay under (landing-page) route group

### Claude's Discretion
- Import path adjustments (source uses `@/components/X`, ours uses `@/components/features/landing/components/X` etc.)
- Any minor TSX fixes needed for compatibility with our tsconfig/Next.js version
- Whether to convert source's `icon-lucide` CSS icon approach to inline SVG or keep as-is
- HeroSection title/subtitle text can be updated to match HSRPVP branding

</decisions>
