## What Was Built

**Task 1 — Foundation:**
- `app/tokens.css` created with 89 CSS custom properties: palette colors, semantic aliases, gradients, shadows, border radii, font references, lobby column widths
- `@import "./tokens.css"` added to `globals.css` after `@source` directive
- `main` rule in `globals.css` stripped of `width: min(94%, 90rem)` and `margin-inline: auto` — prevents landing page hero from being constrained
- `app/layout.tsx` switches Inter to CSS variable mode (`--font-inter`) and adds JetBrains Mono (`--font-jetbrains-mono`), both wired on the `<html>` element
- Hero video asset copied to `public/recording/landing-page-loop.mov` (5.3MB)

**Task 2 — NavBar & Cleanup:**
- `NavBar.tsx` created as `'use client'` component with:
  - Route-aware nav items: LOBBIES (`/lobby`), TEAM BUILDER (`/teambuilder`), COST TABLES (`/costs`) as Next.js `<Link>` components
  - TOURNAMENTS and EVENTS as disabled `<button>` placeholders
  - `usePathname()` drives selection state (no useState for nav)
  - `useAuthContext()` provides `isAuthenticated`, `user`, `loginGuest`
  - Authenticated: profile link + admin link (admin only) + display name in right section
  - Unauthenticated: LOG IN button calls `loginGuest()` directly
  - Scrollable center nav with chevron buttons and wheel-to-scroll
- `Logo.tsx` — SVG gradient diamond logo (coral → amethyst → ocean-blue gradient)
- `GearIcon.tsx` — SVG gear icon with size/color props
- `Header.tsx` and `Header.module.css` deleted
- `app/(landing-page)/layout.tsx` — Header import removed, Footer import removed (Footer comes from root layout)
- `app/(authenticated)/layout.tsx` — Header import removed
- `app/layout.tsx` — `<Header />` replaced with `<NavBar />`
