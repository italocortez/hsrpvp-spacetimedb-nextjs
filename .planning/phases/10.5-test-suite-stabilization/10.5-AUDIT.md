## Category Definitions (per 10.5-RESEARCH.md)

| Category | Description | Fix Pattern |
|----------|-------------|-------------|
| pollution | Test fails because earlier file left DB state | Add afterAll cleanup to the polluter |
| missing-cleanup | Test file creates resources but does not clean up | Add openedLobbyIds[] + afterAll teardown |
| absolute-count | Assertion uses toBe(0) or toBe(N) against counts that drift | Replace with beforeCount + delta pattern |
| ordering | Test B expects artifact created by Test A | Make B self-contained per D-04 |
| stale-assertion | Renamed column/enum from 10.1/10.4 | Update to current name |
| seeding-gap | Test expects pre-seeded data that is not seeded globally | Self-seed per D-04/D-09 |
| awaiting-result | Lobby stuck in AwaitingResult, needs admin_void_match | Add admin harness + admin_void_match cleanup |
| over-seeded | Test inserts too many entities for scenario | Trim per D-11 |
