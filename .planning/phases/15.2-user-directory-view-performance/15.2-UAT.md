note: |
  Wording correction needed in spec: the parenthetical "eviction path is non-guest only" is inaccurate. Per userDeletionHelper.ts:71-87, the hard-delete fast-path triggers only when BOTH `isGuest=true` AND `hasHistoryReferences=false`. The test assertion itself is correct (it scoped to "guest user with no history references") — only the parenthetical oversimplifies the rule.
