## Lessons Learned

- **`@keyframes` cross-module references are silent no-ops.** CSS Modules scope `@keyframes` names per file; a `.imposition { animation: fade-in }` rule in `Teamslot.module.css` cannot see `@keyframes fade-in` defined in `page.module.css`. The animation silently resolves to no motion with no build-time warning. Plan 01 moved `@keyframes fade-in` to co-locate with `.imposition`; Plan 07 confirmed the mirror case: `@keyframes spin` in `page.module.css` was orphan dead code even though two other files use the name locally. New Rule 6 Rationale section codifies the invariant.
- **Pre-sweep grep is a correctness gate, not a style preference.** The CONTEXT.md D-02 list is a pre-phase claim; the pre-sweep grep is the runtime verification. Plan 07 ran the audit and found zero consumers for all 11 rules — sweep proceeded cleanly. Had any consumer surfaced, D-11's "forward-fix unless sweep regression" clause would have kicked in; the sweep would have been revised, not proceeded.
- **Phase 16.1 Plan 06 `.paths > button` cascade fix (commit `7d1745f`) is the canonical lesson for container-only cross-feature duplications.** Initial D-08 duplication copied only the `.paths` container rule (per Pitfall 6); runtime surfaced that `FilterButtonGroup` renders unclassed `<button>` children that relied on the drafting module's `.paths > button` descendant cascade. Forward-fix restored the cascade rules into `LightconeCostTable.module.css`. Rule-of-thumb for future cross-feature duplications with descendant selectors: **copy the container rule + every descendant cascade targeting tags/classes the consumer actually renders**. A grep at `filterStyles.paths` call sites tells you what children are inside — `<FilterButtonGroup>` → buttons → `.paths > button` cascade required.
- **The phase validates the doc+grep enforcement model for R8.** Rule 6 is enforced by two ripgrep one-liners (from CONTEXT.md § Verification surface). Both return zero matches post-Plan 06; Plan 07 formalises the rule in the doc. No AST tooling; no PR-template checkbox; just a diff that fails two grep patterns. Scales as long as reviewer attention is intact. ESLint rule still deferred per D-24.
