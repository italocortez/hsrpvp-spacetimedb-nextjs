## Decisions Made

- **Atomic Task 2 bundles page.module.css thinning with TSX wiring.** Two separate commits would leave an intermediate state where TeamRoster.tsx imports `./TeamRoster.module.css` while `.roster` still lives in `page.module.css` — double specificity, class duplication risk. Same pattern as Plan 01.
- **Handlers attach to the root `.roster` div only.** Attaching to an inner container (e.g. `.charactersContainer`) would miss the padding/gap around the character grid, which users reasonably treat as part of "the roster". Matches the previous `.roster:hover` CSS selector semantics 1:1.
- **No class renames.** TSX call sites already use `styles.roster` and `styles.charactersContainer`; preserving the names avoids a rename wave at zero correctness cost.
- **`useState` reused from existing import.** Plan 01 already imported `useState, useCallback` at TeamRoster.tsx L2 — no new React imports needed, just a second `useState` call inside the component body.
