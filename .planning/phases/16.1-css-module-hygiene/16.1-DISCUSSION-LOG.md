## Cross-component cascades

Ground truth: only ONE true cross-component cascade exists in page.module.css — `.roster:hover .clearButton` (line 106). `.roster` lives in TeamRoster, `.clearButton` in Teamslot. All other hover/descendant/option selectors stay self-contained.

| Option | Description | Selected |
|--------|-------------|----------|
| JS-driven hover state | TeamRoster tracks hover via React state + prop into Teamslot. ~4 lines. (Recommended) | ✓ |
| `:global(.clearButton)` from TeamRoster module | Keep cascade but export class as global name. Leaks global name; collision risk. | |
| Duplicate as `.slot:hover .clearButton` in Teamslot | Semantic shift to per-slot hover; breaks in gaps between slots. | |
| DOM restructure + pure-CSS sibling selector | Re-parent the clearButton. Risk to drag/drop + absolute positioning. | |

**User's choice:** JS-driven hover state.
**Notes:** Clean React data flow; preserves exact UX (hover-anywhere-on-roster reveals clear-button); survives future refactors.

## Page vs component boundary — dead rules

Investigation surfaced that `.main` has zero usages in the codebase (the only hit for `styles.main` is in `app/(public)/layout.tsx` which imports a different module). Extended grep also showed `.confirmation*`, `.dangerous`, `@keyframes grow-fade-in`, `@keyframes spin` are all dead.

| Option | Description | Selected |
|--------|-------------|----------|
| Remove while migrating | Zero-reference classes get deleted, not relocated. Logged in commit. (Recommended) | ✓ |
| Preserve everything as-is | Move every rule by prefix/concern even if unused. Safer against miss; ships dead CSS forever. | |
| Quarantine in `_unused.module.css` | Middle-ground; adds a file that shouldn't exist long-term. | |

**User's choice:** Remove while migrating.

## Claude's Discretion (per user directive: "if you see any gray areas, use what's best from web engineering perspective")

- **`@keyframes` co-location (D-03):** `fade-in` migrates to `Teamslot.module.css` alongside its consumer `.imposition`. `grow-fade-in` and `spin` are dead (no `animation:` reference in the file) → delete per D-02.
- **`@media` responsive blocks (D-04):** Each override migrates with its base class. The `@media (max-width: 800px)` block at page.module.css:545 splits: `.charactersContainer` override → TeamRoster, `.path` override → Teamslot.
- **`components/shared/styles/` directory:** Not created in Phase 16.1. LightconeCostTable borrows 4 classes from 1 consumer — below the ≥20 lines × ≥3 sites threshold. Duplicate per ROADMAP scope.
- **ESLint rule:** Deferred to match Phase 16 D-24 pattern (no AST tooling until PR-review repeatedly misses the violation).
- **Sibling naming:** PascalCase mirroring component filename (`Teamslot.tsx` → `Teamslot.module.css`). Matches existing drafting/costs convention.
