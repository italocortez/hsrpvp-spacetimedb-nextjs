## Decisions Made

- **`isRosterHovered` is non-optional, not defaulted.** D-06 requires TeamRoster to always pass it (Plan 02). A default value here would hide the contract and let call sites drift out of compliance silently.
- **Task 2 bundles the `page.module.css` thinning with the import swap.** If the delete landed in a separate commit, there would be a window where Teamslot.tsx references classes that still exist in both files — double specificity risk on the intermediate commit. Atomic swap + delete avoids that.
- **`.charactersContainer` `@media (<=800px)` override left in `page.module.css` for Plan 02** to migrate to `TeamRoster.module.css`. Respects D-04 component-ownership partition.
- **No `:global()` anywhere in the new module** per PATTERNS.md Critical Gotcha 6.
