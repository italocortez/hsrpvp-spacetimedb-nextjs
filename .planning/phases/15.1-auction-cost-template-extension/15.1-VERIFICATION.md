### Data-Flow Trace (Level 4)

These are seed pipeline transformations, not rendering components. The data flow is:
JSON files → extractor functions → `adminBulkUpsert` reducer → DB tables.

| Pipeline Stage | Input | Transform | Output | Status |
|---------------|-------|-----------|--------|--------|
| Character cost extraction | `modeBlock.classic` (EidolonSubBlock or undefined) | `extractEidolonCost` → undefined if absent | `classicCosts ?? ZERO_EIDOLON` | FLOWING |
| Auction cost extraction | `modeBlock.auction` (EidolonSubBlock or undefined) | `extractEidolonCost` → undefined if absent | `auctionBaseBid ?? ZERO_EIDOLON` | FLOWING |
| Skip-mode gate | Both extractors return undefined | `if (!classicCosts && !auctionBaseBid) continue` | Row not emitted | FLOWING |
| Lightcone cost extraction | Identical pattern for SuperpositionSubBlock | `extractSuperpositionCost` | `classicCosts ?? ZERO_SUPERPOSITION` / `auctionBaseBid ?? ZERO_SUPERPOSITION` | FLOWING |

Edge case confirmed: `extractEidolonCost({})` would return `{e0:0..e6:0}` (not undefined), BUT this path is never reached because an empty `{}` mode block has `modeBlock.classic = undefined` and `modeBlock.auction = undefined`. Both extractor calls receive `undefined` → both return `undefined` → skip gate fires. D-09 behavior for empty `{}` blocks is correct.
