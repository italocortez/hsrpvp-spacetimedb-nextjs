# Phase 15.4 Plan 03: Seed pipelines + pairing template + README — Summary

One-line summary: Rewrote both seed pipelines (`scripts/seed-data.ts` production + `test/shared/seed-data.ts` harness) to emit one row per present sub-block with a `draftMode` discriminator, extended `pairing_template.json` to the sibling-block shape with explicit zero-default auction modifiers, and rewrote `test/data-templates/README.md` transform tables so the row-absence rule (D-14) is the governing principle across all three cost domains — code half committed; Task 3 (local `test/data/*.json` re-migration + post-publish reseed) left to user per the CLAUDE.md Gitignore Guardrail.

## What Changed

### Task 1 — scripts/seed-data.ts fan-out rewrite (commit `6dc44f7`)

- **`normalizeCharacterCosts`** (L192-241): replaced the single `rows.push({ ..., classicCosts: classicCosts ?? ZERO_EIDOLON, auctionBaseBid: auctionBaseBid ?? ZERO_EIDOLON })` with a pair of guarded pushes — one row per present sub-block. Absent sub-block = no row for that draftMode. Per-row payload shape now `{ characterName, gameMode, draftMode: 'Classic' | 'Auction', costs: <EidolonCost>, costSetId }`.
- **`normalizeLightconeCosts`** (L244-296): same transform with `SuperimpositionCost` and `lightconeName`.
- **`normalizePairings`** (L299-342): full rewrite. Input type changed from `[mode: string]: number` to `[mode: string]: RawPairingModeBlock`. `RawPairingModeBlock` = `{ classic?: { modifier: number }; auction?: { modifier: number } }`. Per-row payload now includes `draftMode` and reads `modeBlock.classic.modifier` / `modeBlock.auction.modifier` (not a flat scalar).
- **Constant cleanup**: `ZERO_EIDOLON` and `ZERO_SUPERPOSITION` deleted — no remaining references.
- **Verify (grep)**: zero `classicCosts: classicCosts` / `auctionBaseBid` / `ZERO_EIDOLON` / `ZERO_SUPERPOSITION` matches. Six `draftMode: 'Classic' | 'Auction'` matches (expected: 2 per domain × 3 domains).

### Task 2 — Templates + README + harness seed mirror (commit `233ccaa`)

- **`test/data-templates/pairing_template.json`**: both entries (cerydra->anaxa, feixiao->moze) rewritten to sibling-block `{ classic: { modifier }, auction: { modifier } }` per mode. `classic.modifier` preserves the original scalar value (3.0 / 4.0). `auction.modifier` is `0.0` across the board — the first-ever seeded synergy auction modifiers (D-13; values to be tuned in a later phase).
- **`test/data-templates/README.md`**: full rewrite. Row-absence rule (D-14) added as a top-level governing principle. Transform tables for all three domains now describe one-row-per-sub-block emission. New pairing transform section has an input-shape JSON block + a worked example showing the 6-row fan-out (3 modes × 2 draftModes) for a fully-populated entry. Notes section updated: removed "zero-pad on insert (D-07)" language; added explicit "D-14 replaces D-07/D-08" cross-reference.
- **`test/shared/seed-data.ts`**: 1:1 mirror of production. Character / lightcone / pairing loops all rewritten to emit the same shapes as `scripts/seed-data.ts`. `ZERO_EIDOLON` / `ZERO_SUPERPOSITION` removed. Types updated (`RawPairingModeBlock` + `PairingSubBlock`).
- **Verify (grep)**: `node -e JSON.parse(...)` on the pairing template exits 0. Zero old-field matches in harness. README has 31 total references to `draftMode | sub-block | pairing` across the new tables + notes.
