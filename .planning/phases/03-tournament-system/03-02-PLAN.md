**CREATE tournamentRegistration.ts with 4 reducers:**

**1. register_for_tournament:**
- Permission: `getAuthenticatedUser(ctx)`
- Args: tournamentId (u32), teamGroupId (u32 — 0 means solo/no team)
- Validation:
  - Tournament must exist and be in Registration or Seeding stage
  - Player must not already be registered: check `(ctx.db.TournamentParticipant as any).primaryKey.find({ tournamentId, userId: user.id })`
  - If tournament.requireVerified && user.isGuest → throw SenderError
  - If tournament.requireRoster → check user has at least one active HsrAccount: `[...ctx.db.HsrAccount.user_id.filter(user.id)].some(a => a.isActive)`. If not, throw SenderError.
  - If tournament.minimumMmr > 0 → check MmrRating table (or skip for now since MMR isn't implemented yet — just allow if minimumMmr > 0 but no MMR record found; document this as "MMR check deferred to Phase 5")
  - If teamGroupId !== 0, verify TournamentTeam.id.find(teamGroupId) exists and belongs to this tournament
  - If teamGroupId !== 0, verify team has room (count TournamentParticipant rows with this teamGroupId < tournament.teamSize)
  - Check participant count: count `[...ctx.db.TournamentParticipant.tournament_id.filter(tournamentId)]` that are NOT waitlisted
  - If count >= tournament.maxParticipants:
    - If tournament.waitlistEnabled: insert with isWaitlisted = true
    - Else: throw SenderError "Tournament is full"
  - If tournament.requireApproval: insert with status Registered and approvedByToAt = undefined (TO must approve later)
  - Else: insert with status Registered, approvedByToAt = ctx.timestamp (auto-approved)
- Determine participantType: if teamGroupId !== 0 → Team, else → Individual
- Get active HSR account id if any: `const activeAccount = [...ctx.db.HsrAccount.user_id.filter(user.id)].find(a => a.isActive); const hsrAccountId = activeAccount ? activeAccount.id : undefined;`
- Insert TournamentParticipant row with all fields

- Update status to { tag: 'Withdrawn', value: {} } via delete + insert pattern (composite PK)

**3. approve_participant:**
- Permission: `ensureTournamentAccess(ctx, tournamentId)`
- Args: tournamentId (u32), userId (u32)

- Update request: set isPending = false (delete + insert)

**4. reject_team_request:**

- Reset the player's TournamentParticipant: set teamGroupId = undefined, participantType = Individual (delete + insert)

**6. disband_tournament_team:**
- Permission: `getAuthenticatedUser(ctx)` — must be team captain
- Args: teamId (u32)
- Find team, validate caller is captainUserId
- Tournament must be in Registration stage (can't disband mid-tournament)
- For all TournamentParticipant rows with teamGroupId = teamId: reset teamGroupId = undefined, participantType = Individual (delete + insert for each)
- Delete all pending TournamentTeamRequest rows for this team
- Delete the TournamentTeam row
