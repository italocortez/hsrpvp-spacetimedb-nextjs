Create `spacetimedb/src/reducers/costSetManagement.ts` with 8 reducers:

**1. create_cost_set:**
- Permission: `ensureTournamentHost(ctx)` (TournamentHost, Moderator, or Admin)
- Args: name (string), sourceSetId (u32), gameModeTag (string)
- Validate: name.trim() length 1-100
- Validate: gameModeTag is a valid GameMode tag (MemoryOfChaos, ApocalypticShadow, AnomalyArbitration)
- If sourceSetId !== 0, validate CostSet.id.find(sourceSetId) exists and isPublished
- Insert CostSet metadata row: { id: 0, name: name.trim(), creatorId: user.id, gameMode: { tag: gameModeTag, value: {} }, isPublished: false, isDraft: true, isLocked: false, ...auditInsert(ctx, user.id) }
- Capture the inserted cost set's id (insert returns the row with auto-inc id)
- Clone character costs from source:
  ```typescript
  const sourceCharCosts = [...ctx.db.HsrCharacterCost.cost_set_id.filter(sourceSetId)];
  for (const row of sourceCharCosts) {
      if (row.gameMode.tag === gameModeTag) {
          ctx.db.CostSetDraftCharacter.insert({
              costSetId: costSet.id,
              characterName: row.characterName,
              gameMode: row.gameMode,
              classicCosts: row.classicCosts,
              auctionBaseBid: row.auctionBaseBid,
              ...auditInsert(ctx, user.id),
          } as any);
      }
  }
  ```
- Clone lightcone costs similarly from HsrLightconeCost.cost_set_id.filter(sourceSetId), filtering by gameModeTag
- Clone synergy costs from HsrSynergyCost.cost_set_id.filter(sourceSetId), filtering by gameModeTag

NOTE: `ctx.db.Table.insert()` returns the inserted row with the auto-incremented id. Use: `const costSet = ctx.db.CostSet.insert({ ... } as any);`

**2. edit_draft_character_cost:**
- Permission: `getAuthenticatedUser(ctx)` — then validate user owns the cost set
- Args: costSetId (u32), characterName (string), gameModeTag (string), classicCostsJson (string), auctionBaseBidJson (string)
- Find CostSet by id, validate: costSet.creatorId === user.id OR isRoleAtLeast(user.role, 'Moderator')
- Validate isDraft === true (cannot edit published sets directly)
- Parse classicCostsJson and auctionBaseBidJson as JSON objects with keys e0-e6 (all f32)
- Find existing draft row via `(ctx.db.CostSetDraftCharacter as any).primaryKey.find({ costSetId, characterName, gameMode: { tag: gameModeTag, value: {} } })`
  - NOTE: finding by composite PK with enum fields may need iteration instead. Use filter pattern:
  ```typescript
  const drafts = [...ctx.db.CostSetDraftCharacter.cost_set_id.filter(costSetId)];
  const existing = drafts.find(d => d.characterName === characterName && d.gameMode.tag === gameModeTag);
  ```
- If found: delete + insert with updated values
- If not found: insert new draft row

**3. edit_draft_lightcone_cost:**
- Same pattern as edit_draft_character_cost but for lightcones
- Args: costSetId (u32), lightconeName (string), gameModeTag (string), classicCostsJson (string), auctionBaseBidJson (string)
- classicCostsJson and auctionBaseBidJson have keys s1-s5 (all f32)

**4. edit_draft_synergy_cost:**
- Same permission pattern
- Args: costSetId (u32), sourceName (string), targetName (string), gameModeTag (string), costModifier (f32)
- Find existing draft row in CostSetDraftSynergy via filter on cost_set_id + manual match
- If found: delete + insert with updated costModifier
- If not found: insert new draft row

**5. publish_cost_set:**
- Permission: `getAuthenticatedUser(ctx)` — then validate ownership or Moderator+
- Args: costSetId (u32)
- Find CostSet, validate isDraft === true
- **Phase A: Copy draft character costs to live HsrCharacterCost table:**
  ```typescript
  const draftChars = [...ctx.db.CostSetDraftCharacter.cost_set_id.filter(costSetId)];
  for (const draft of draftChars) {
      // Check if a live row already exists for this costSetId+char+gameMode
      const liveRows = [...ctx.db.HsrCharacterCost.cost_set_id.filter(costSetId)];
      const existingLive = liveRows.find(r => r.characterName === draft.characterName && r.gameMode.tag === draft.gameMode.tag);
      if (existingLive) {
          ctx.db.HsrCharacterCost.delete(existingLive);
      }
      ctx.db.HsrCharacterCost.insert({
          characterName: draft.characterName,
          gameMode: draft.gameMode,
          classicCosts: draft.classicCosts,
          auctionBaseBid: draft.auctionBaseBid,
          costSetId: costSetId,
          ...auditInsert(ctx, user.id),
      } as any);
  }
  ```
- **Phase B: Copy draft lightcone costs to live HsrLightconeCost table** (same pattern)
- **Phase C: Copy draft synergy costs to live HsrSynergyCost table:**
  - For synergy, since it uses autoInc id PK, find existing by [sourceName, targetName, gameMode.tag, costSetId] via iteration
  - If found: update via id.update()
  - If not found: insert
- **Phase D: Clean up draft tables** — delete all draft rows for this costSetId from all 3 draft tables
- **Phase E: Update CostSet metadata** — set isPublished = true, isDraft = false, auditUpdate

**6. lock_cost_set:**
- Permission: ownership or Moderator+
- Args: costSetId (u32)
- Cannot lock costSetId 0 (the default set)
- Find CostSet, validate isPublished === true and isLocked === false
- Set isLocked = true — prevents new lobbies/tournaments from selecting this cost set
- Existing lobbies already using this set continue unaffected
- auditUpdate
- NOTE: In Phase 9, the lobby close reducer will check if a locked cost set has zero active lobbies and auto-unpublish it. For now, lock is a manual precursor to unpublish.

**7. unpublish_cost_set:**
- Permission: ownership or Moderator+
- Args: costSetId (u32)
- Cannot unpublish costSetId 0 (the default set)
- Find CostSet, validate isPublished === true AND isLocked === true (must lock before unpublishing)
- Set isPublished = false, isLocked = false (live cost rows remain in tables but CostSet metadata signals "don't broadcast")
- auditUpdate

**8. delete_cost_set:**
- Permission: ownership or Moderator+
- Args: costSetId (u32)
- Cannot delete costSetId 0 (the default set is never deleted via reducers)
- Find CostSet, validate isPublished === false (must unpublish before deleting — never delete directly from live)
- Delete all live character cost rows with this costSetId: `for (const row of [...ctx.db.HsrCharacterCost.cost_set_id.filter(costSetId)]) ctx.db.HsrCharacterCost.delete(row);`
- Delete all live lightcone cost rows with this costSetId
- Delete all live synergy cost rows with this costSetId
- Delete any remaining draft rows (all 3 tables)
- Delete the CostSet metadata row
- NOTE: Only admins can delete cost data directly from the cost tables (via existing admin_delete_row). This reducer enforces the lock → unpublish → delete lifecycle.

```typescript
spacetimedb.view(
    { name: 'view_my_cost_sets', public: true },
    t.array(CostSet.rowType),
    (ctx) => {
        const mapping = ctx.db.UserIdentity.identity.find(ctx.sender);
        if (!mapping) return [];
        const user = ctx.db.User.id.find(mapping.userId);
        if (!user) return [];
        return [...ctx.db.CostSet.creator_id.filter(user.id)];
    }
);
```

**View 7: My Draft Character Costs (per-user)**
```typescript
spacetimedb.view(
    { name: 'view_my_draft_character_costs', public: true },
    t.array(CostSetDraftCharacter.rowType),
    (ctx) => {
        const mapping = ctx.db.UserIdentity.identity.find(ctx.sender);
        if (!mapping) return [];
        const user = ctx.db.User.id.find(mapping.userId);
        if (!user) return [];
        // Get all cost sets owned by this user
        const mySets = [...ctx.db.CostSet.creator_id.filter(user.id)];
        const mySetIds = new Set(mySets.map(s => s.id));
        // Return all draft character rows for those sets
        const results: any[] = [];
        for (const row of ctx.db.CostSetDraftCharacter.iter()) {
            if (mySetIds.has(row.costSetId)) results.push(row);
        }
        return results;
    }
);
```

```
Cost Set Management
===================

CostSet (PK: id autoInc)
├── CostSetDraftCharacter (PK: [costSetId, characterName, gameMode]) [PRIVATE]
├── CostSetDraftLightcone (PK: [costSetId, lightconeName, gameMode]) [PRIVATE]

└── Live cost tables (FK: costSetId):
    ├── HsrCharacterCost (PK: [characterName, gameMode, costSetId])
    ├── HsrLightconeCost (PK: [lightconeName, gameMode, costSetId])
    └── HsrSynergyCost (PK: id autoInc, index on costSetId)
```

2. Draft/publish workflow:
```
create_cost_set (clone from source) → Edit draft tables → publish_cost_set → Live tables updated
     ↓                                    ↓                     ↓
  CostSet metadata               CostSetDraft* tables    HsrCharacterCost/etc.
  (isDraft=true)                 (PRIVATE, per-user)     (costSetId = new set id)
```

3. Key rules:
- costSetId=0 is the default set (cannot be unpublished or deleted)
- Draft tables are private — not broadcast to clients
- Per-user views (view_my_draft_*_costs) allow TOs to see only their own drafts
- Publishing copies draft → live and cleans up draft rows
- Cost sets are per-game-mode (one CostSet covers one GameMode)
- Cloning copies all characters/lightcones/synergies for the selected gameMode from the source set
