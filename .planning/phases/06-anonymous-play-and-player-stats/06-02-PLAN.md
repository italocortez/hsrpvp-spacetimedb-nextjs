**A. Anonymous Label Helper** (`spacetimedb/src/helpers/anonymousLabels.ts`):

Create a helper that computes deterministic anonymous labels per D-04 and D-05.

```typescript
/**
 * Computes anonymous label for a lobby member based on team side and join order.
 * Labels: "Blue-1", "Blue-2", "Red-1", "Red-2", "Spectator-1", "Coach-Blue", "Coach-Red"
 * Deterministic: same LobbyMember data always produces same label.
 */
export function computeAnonymousLabel(ctx: any, lobbyId: number, userId: number): string
```

Implementation:
1. Look up the target member: `[...ctx.db.LobbyMember.by_lobby_and_user.filter([lobbyId, userId])][0]`.
2. If not found, return `"Unknown"`.
3. If member `isCoach` is true, return `"Coach-${member.teamSlot.tag}"` (e.g., "Coach-Blue").
4. Get all members in the same lobby on the same team: `[...ctx.db.LobbyMember.lobby_id.filter(lobbyId)].filter(m => m.teamSlot.tag === member.teamSlot.tag && !m.isCoach)`.
5. Sort by `createdDate` ascending (join order — earlier = lower number). Use `Number(m.createdDate.microsSinceUnixEpoch / 1000n)` for comparison.
6. Find the index of the target userId in the sorted list.
7. Return `"${member.teamSlot.tag}-${index + 1}"` (e.g., "Blue-1", "Red-2", "Spectator-3").

**B. Ownership Validation Helper** (`spacetimedb/src/helpers/ownershipValidation.ts`):

Per D-17 through D-20: Create a helper function that validates a player owns a character via HsrAccountCharacter. Phase 9 will wire this into pick/ban reducers.

```typescript
/**
 * Validates that the user owns the specified character on their active HSR account.
 * Returns true if owned or if ownership check is disabled.
 * For tournament matches, checks against TournamentPlayerAccount locked accounts.
 */
export function validateCharacterOwnership(
    ctx: any,
    userId: number,
    characterName: string,
    lobbyId: number
): { valid: boolean; reason?: string }
```

Implementation:
1. Look up the Lobby: `ctx.db.Lobby.id.find(lobbyId)`.
2. If lobby not found or `lobby.requireOwnership === false`, return `{ valid: true }` (ownership check disabled).
3. If `lobby.isTournamentControlled && lobby.tournamentId`:
   - Look up TournamentPlayerAccount rows: `[...ctx.db.TournamentPlayerAccount.by_tournament_and_user.filter([lobby.tournamentId, userId])]`.
   - For each locked account, check if character exists: `[...ctx.db.HsrAccountCharacter.by_account_and_character.filter([account.hsrAccountId, characterName])][0]`.
   - If found in ANY locked account, return `{ valid: true }`.
   - If none match, return `{ valid: false, reason: 'You do not own this character on any registered tournament account.' }`.
4. Else (non-tournament):
   - Get user's active HSR account: `[...ctx.db.HsrAccount.user_id.filter(userId)].find(a => a.isActive)`.
   - If no active account, return `{ valid: false, reason: 'No active HSR account found.' }`.
   - Check HsrAccountCharacter: `[...ctx.db.HsrAccountCharacter.by_account_and_character.filter([activeAccount.id, characterName])][0]`.
   - If found, return `{ valid: true }`. If not, return `{ valid: false, reason: 'You do not own this character.' }`.

NOTE: Check if `by_account_and_character` index exists on HsrAccountCharacter. Read the table file first. If it only has a single-column index, use the fallback pattern: `[...ctx.db.HsrAccountCharacter.account_id.filter(accountId)].find(r => r.characterName === characterName)`.
