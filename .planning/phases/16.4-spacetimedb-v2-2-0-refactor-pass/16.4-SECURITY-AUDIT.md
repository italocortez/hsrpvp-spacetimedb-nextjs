- Same `.catch()` error UX pattern (`BulkUpsert.tsx:359` — `.catch((err: any) => ...)` and `.finally(() => setIsSubmitting(false))` at line 362).

- Risk classification: identical to T-16.4-06-01 (Tampering / regression). The mitigation pattern is identical.

**Disposition:** Treated as covered by T-16.4-06-01's mitigation pattern. No blocker. Recommend the next phase that touches BulkUpsert documents this site explicitly in its threat register so the site→threat mapping is complete.
