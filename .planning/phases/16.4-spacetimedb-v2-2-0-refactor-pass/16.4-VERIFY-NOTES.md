| Table | Accessor | Columns | String columns | Scan-cost case for v2.2.0 bytes-key B-tree? |

The `--clear-database` republish does NOT exercise the same code path as plain `spacetime publish`:
- `--clear-database`: drops all rows, reapplies schema, no migration prompt (because tables are empty)
- plain `spacetime publish`: keeps existing rows, runs schema diff, fires destructive-migration prompt only on schema delta — the explicit path Plan 07 verifies

So the human-action checkpoint is still required for the plain-publish path; it surfaces additional failure modes (migration prompt, schema delta detection on a populated DB) that the auto-republish does not.
