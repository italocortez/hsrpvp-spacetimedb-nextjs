**4. Create `spacetimedb/src/helpers/accountRating.ts`:**

Two exported functions:

`computeAccountRating(ctx: any, hsrAccountId: number): number` -- Pure computation:
- Read all HsrAccountCharacter rows for this hsrAccountId via `by_account` index
- Read all HsrAccountLightcone rows for this hsrAccountId via `by_account` index
- For each character, look up its cost from HsrCharacterCost (costSetId=0, characterName, gameMode=MemoryOfChaos as reference mode) using `by_cost_set_character_mode` index. Use e0 cost as base value. Add eidolon bonus: eidolonLevel * 50 (each eidolon adds ~50 points out of 1000 scale).
- For each lightcone, look up its cost from HsrLightconeCost (costSetId=0, lightconeName) using `by_cost_set_and_name` index. Use s1 cost as base value. Add superimposition bonus: (superimposition - 1) * 20.
- Sum all character and lightcone values, then normalize to 0-1000 scale: `Math.min(1000, Math.round(totalValue / maxExpectedValue * 1000))` where maxExpectedValue = 500 (tunable constant at top of file).
- If no characters and no lightcones exist, return 0.

`updateAccountRating(ctx: any, hsrAccountId: number, actingUserId: number): void` -- DB wrapper:
- Call `computeAccountRating(ctx, hsrAccountId)` to get the new rating
- Read the HsrAccount row via `id.find(hsrAccountId)`
- If the computed rating differs from the stored `accountRating`, update via `id.update({...account, accountRating: newRating, ...auditUpdate(ctx, account, actingUserId)})`.

export const record_game_scores = spacetimedb.reducer({
    matchResultId: t.u32(),
    gameNumber: t.u8(),

Implementation logic:
1. `getAuthenticatedUser(ctx)` for auth
2. Find MatchResultRecord by `id.find(matchResultId)`. Throw `'Match result not found.'` if missing.
3. Verify status is Pending: `matchResult.status.tag !== 'Pending'` throws `'Scores can only be recorded when the match is in Pending status.'`
4. Validate winnerTeamSide is "Blue" or "Red": throw `'winnerTeamSide must be "Blue" or "Red".'` if invalid.
5. Determine caller authority:
   - Check if caller is a MatchResultParticipant via `by_result_and_user.filter([matchResultId, user.id])`.
   - If participant: they are a captain (must check `isCaptain`). They can only set scores for their OWN side. If they attempt to set the opposite side's scores (e.g., Blue captain setting teamRedScore), throw `'Captains can only enter scores for their own side.'`. Check: if participant.teamSide.tag is 'Blue', reject if any teamRed* args are provided (not undefined). Vice versa for Red.
   - If NOT a participant: check spectator referee path. Read LobbyMember via `by_lobby_and_user.filter([matchResult.lobbyId, user.id])`. Must be a LobbyMember with `isReferee=true`. Must have `matchResult.refereeFullControl === true`. Throw `'You are not a participant or authorized referee of this match.'` if neither condition met. Spectator referee can set BOTH sides' scores.
6. Read the Lobby to get `gameMode`: `ctx.db.Lobby.id.find(matchResult.lobbyId)`. Use lobby's gameMode for the MatchResultGame row.
7. Upsert MatchResultGame: Look for existing row via `by_result_and_game.filter([matchResultId, gameNumber])[0]`.
   - If exists: `ctx.db.MatchResultGame.delete(existing)` then `ctx.db.MatchResultGame.insert({...})` with updated fields. Preserve existing values for fields the caller did NOT provide (undefined args mean "don't change"). Use `args.teamBlueScore !== undefined ? args.teamBlueScore : existing.teamBlueScore` pattern for each optional field.
   - If not exists: `ctx.db.MatchResultGame.insert({...})` with provided values.
   - Set `winnerTeamSide: { tag: args.winnerTeamSide, value: {} } as any`
   - Set `validationStatus: { tag: 'Pending', value: {} } as any`
   - Set `validatedByUserId: undefined`
   - Use audit columns: `auditInsert(ctx, user.id)` for new, `auditUpdate(ctx, existing, user.id)` for update (preserve created* from existing).
8. Console log: `[MATCH] Game ${gameNumber} scores recorded for match result #${matchResultId} by user #${user.id}`
