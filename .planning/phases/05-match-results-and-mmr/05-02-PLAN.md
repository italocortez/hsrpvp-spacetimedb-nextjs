**`getKFactor(matchesPlayed: number, config: EloConfigValues): number`**
Per D-14:
- If matchesPlayed <= config.newThreshold (20): return config.kFactorNew (40)
- If matchesPlayed <= config.midThreshold (100): return config.kFactorMid (20)
- Else: return config.kFactorVet (10)

**`calculateExpectedScore(playerEffective: number, opponentEffective: number): number`**
Per D-15:
```
return 1 / (1 + Math.pow(10, (opponentEffective - playerEffective) / 400));
```

**`calculateRatingChange(kFactor: number, actualResult: number, expectedScore: number): number`**
Per D-15:
```
return Math.round(kFactor * (actualResult - expectedScore));
```
Returns a signed integer (positive for gain, negative for loss). Use Math.round to produce integer deltas.

**`calculateTeamEffective(teamRatings: number[], sizeBonus: number, spreadDivisor: number): number`**
Per D-18 through D-20:
```
const avg = teamRatings.reduce((a, b) => a + b, 0) / teamRatings.length;
if (teamRatings.length === 1) return avg;  // No modifier for solo
const stdev = Math.sqrt(
    teamRatings.reduce((sum, r) => sum + (r - avg) ** 2, 0) / teamRatings.length
);
return Math.round(avg + sizeBonus * (teamRatings.length - 1) - stdev / spreadDivisor);
```

**`calculateAccountModifier(higherAccountRating: number, lowerAccountRating: number, maxAccountBonus: number): number`**
Per D-24:
```
const gap = Math.abs(higherAccountRating - lowerAccountRating);
return Math.round((gap / 1000) * maxAccountBonus);
```
Returns the modifier to add to the higher-account-rating side's effective rating.

**2. Create `spacetimedb/src/helpers/statsIncrement.ts` -- PlayerStat and PlayerRelationship helpers:**

Both functions access ctx.db to read/write stat tables. They follow the composite PK delete+insert upsert pattern established in the codebase.

**`incrementPlayerStat(ctx: any, userId: number, gameMode: any, draftMode: any, isWin: boolean, isDraw: boolean, actingUserId: number): void`**
- Look up existing: `[...ctx.db.PlayerStat.by_user_mode_draft.filter([userId, gameMode, draftMode])][0]`
- If exists: delete + insert with incremented fields:
  - `matchesPlayed: existing.matchesPlayed + 1`
  - `wins: existing.wins + (isWin ? 1 : 0)`
  - `losses: existing.losses + (!isWin && !isDraw ? 1 : 0)`
  - `draws: existing.draws + (isDraw ? 1 : 0)`
  - `matchesSpectated: existing.matchesSpectated` (unchanged)
  - Preserve existing audit created* via `auditUpdate(ctx, existing, actingUserId)`
- If not exists: insert new row with initial values (matchesPlayed=1, wins/losses/draws as appropriate, matchesSpectated=0) via `auditInsert(ctx, actingUserId)`

**`incrementPlayerRelationship(ctx: any, userId: number, otherUserId: number, gameMode: any, draftMode: any, isAlly: boolean, didWin: boolean, actingUserId: number): void`**
- Look up existing: `[...ctx.db.PlayerRelationship.by_user_and_other_mode_draft.filter([userId, otherUserId, gameMode, draftMode])][0]`
- If exists: delete + insert with incremented fields based on isAlly:
  - If isAlly: `matchesAsAlly + 1`, `winsAsAlly + (didWin ? 1 : 0)`, opponent fields unchanged
  - If opponent: `matchesAsOpponent + 1`, `winsAsOpponent + (didWin ? 1 : 0)`, ally fields unchanged
  - Preserve existing audit created* via `auditUpdate(ctx, existing, actingUserId)`
- If not exists: insert new row with isAlly or isOpponent initial values (1 match, 0/1 wins) via `auditInsert(ctx, actingUserId)`

NOTE: PlayerRelationship is directional. For a pair (A, B), you must call this TWICE: once for userId=A, otherUserId=B, and once for userId=B, otherUserId=A. The finalization reducer handles this double-call.
