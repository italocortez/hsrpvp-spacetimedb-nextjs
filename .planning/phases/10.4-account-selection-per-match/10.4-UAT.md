### Setup Gotchas (save test generation time)
- **Character names**: lowercase, no spaces — `march7th`, `danheng`, `kafka`, `silverwolf`, `fuxuan`
- **UID format**: exactly 9 digits (e.g. `800100001`)
- **Role promotion**: `manage-user.ts` takes **username** not userId, role is PascalCase (`Admin` not `admin`), script may crash on cleanup but role is set — wrap in try/catch
- **Enum params**: `{ tag: 'BluePlayer' }` not `{ tag: 'Blue', value: { position: 0 } }`; reducer params like `lobbySlot` not `newSlot` — check bindings
- **Host has no LMA**: `create_lobby` doesn't auto-create LMA (host starts as Spectator), only `join_lobby` does
- **maxAccountsPerPlayer**: not in createTournament/updateTournament reducers — set via `spacetime sql UPDATE`
- **requireOwnership**: defaults to false — must be set true for ownership validation to run
- **`subscribeToAllTables()`**: HsrAccount and HsrAccountCharacter are PRIVATE — use `spacetime sql` for those tables, subscription cache won't have them
