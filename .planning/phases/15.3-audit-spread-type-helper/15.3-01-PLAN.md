Key helper contracts (from `spacetimedb/src/helpers/auditHelpers.ts`):

```typescript
export type AuditFields = {
    createdById: number;
    createdDate: Timestamp;
    lastModifiedById: number;
    lastModifiedDate: Timestamp;
};

export function insertWithAudit<T extends object>(
    ctx: any, row: T, userId: number = SYSTEM_USER_ID,
): T & AuditFields;

export function updateWithAudit<T extends { createdById: number; createdDate: Timestamp }>(
    ctx: any, existing: T, changes: Partial<T>, userId: number = SYSTEM_USER_ID,
): T & AuditFields;
```

   ```ts
   // BEFORE

   import { insertWithAudit, updateWithAudit } from '../helpers/auditHelpers';
   // (SYSTEM_USER_ID import stays if used elsewhere)
   ```

2. **Plain inserts (P1 pattern):** Transform per PATTERNS.md Analog A:
   ```ts
   // BEFORE
   ctx.db.CalendarEvent.insert({
       id: 0,
       userId: user.id,
       title,
       startTimestamp,
       ...auditInsert(ctx, user.id),
   } as any);

   // AFTER
   ctx.db.CalendarEvent.insert(insertWithAudit(ctx, {
       id: 0,
       userId: user.id,
       title,
       startTimestamp,
   }, user.id));
   ```

3. **Direct partial updates (P2 pattern):** Transform per PATTERNS.md Analog A (admin.ts L176):
   ```ts
   // BEFORE
   ctx.db.X.pk.update({
       ...row,
       fieldA: newValue,
       ...auditUpdate(ctx, row, user.id),
   });

   // AFTER
   ctx.db.X.pk.update(updateWithAudit(ctx, row, { fieldA: newValue }, user.id));
   ```

4. Drop the trailing `} as any);` closure on every audit-merge insert object (per D-16 — if a nested tagged-enum field still needs `as any`, the cast moves to that nested field only).

5. Preserve the exact `userId` argument from the original call (per T-15.3-user-id-drift mitigation).

6. No delete+insert-carry sites in these 4 files — do not apply the carry pattern here.
