## Option Decision (Task 1)

- **Option β** (delete `auditInsert`): would require splitting 9 conditional sites
  into matching if/else branches — each split duplicates the explicit row literal
  once per branch. Zero runtime benefit. Rejected.
- **Option α** (keep `auditInsert` exported, documented as RESTRICTED USE):
  zero code churn, preserves the two-tier API (high-level helpers for plain
  inserts/updates, primitive for conditional upserts). **Selected.**
