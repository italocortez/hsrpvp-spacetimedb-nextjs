### P4. Delete+insert-carry — **KEEP PRIMITIVE** (no migration)

**Analog:** `spacetimedb/src/reducers/admin.ts` L514-522 (HsrCharacterCost composite-PK re-insert):

    draftMode: existing.draftMode,

### P7. `mergeForUpdate` typed signature (Wave 2b D-17) — 1 signature + 5 callers

**Current signature** — `spacetimedb/src/reducers/admin.ts` L91-111:

```typescript
// BEFORE — forces `existing as any` + `FIELDS as any` at every call site
function mergeForUpdate<T extends Record<string, any>>(
    existing: T,
    incoming: Record<string, any>,
    fields: (keyof T)[]
): T {
    const merged: T = { ...existing };
    for (const f of fields) {
        const key = f as string;
        if (!(key in incoming)) {
            throw new Error(`mergeForUpdate: missing key '${key}' — validateKeys contract broken`);
        }
        if (incoming[key] != null) {
            (merged as any)[key] = incoming[key];
        }
    }
    return merged;
}
```

**After** — tighter generic:

```typescript
function mergeForUpdate<T extends Record<string, any>, K extends keyof T & string>(
    existing: T,
    incoming: Partial<Record<K, unknown>>,
    fields: readonly K[]
): T {
    // body unchanged
}
```

**Caller-side diff** (admin.ts L343-347, L375-376):

```typescript
// BEFORE
const HSR_CHARACTER_FIELDS = [
    'displayName', 'aliases', 'rarity', 'path', /* ... */
];
// ...
const merged = mergeForUpdate(existing as any, incoming, HSR_CHARACTER_FIELDS as any);

// AFTER
const HSR_CHARACTER_FIELDS = [
    'displayName', 'aliases', 'rarity', 'path', /* ... */
] as const;   // <-- add `as const`
// ...
const merged = mergeForUpdate(existing, incoming, HSR_CHARACTER_FIELDS);  // 0 `as any`
```

Apply identically at admin.ts L463 (HsrLightcone), L512 (HsrCharacterCost), L561 (HsrLightconeCost), L609 (HsrSynergyCost).

### C1. COUNTER-EXAMPLE — `server_set_datetime` manual audit write — **NO-TOUCH**

**Source:** `spacetimedb/src/reducers/server.ts` L293-322 (Pitfall 6 target):

```typescript
// DO NOT MIGRATE — these sites intentionally write custom timestamps
if (field === 'lastSeenAt') {
    ctx.db.UserIdentity.identity.update({
        ...row,
        lastSeenAt: ts,                             // <-- custom ts, NOT ctx.timestamp
        lastModifiedById: SYSTEM_USER_ID,
        lastModifiedDate: ctx.timestamp,
    });
} else if (field === 'createdDate') {
    ctx.db.UserIdentity.identity.update({
        ...row,
        createdDate: ts,                            // <-- custom ts override
        lastModifiedById: SYSTEM_USER_ID,
        lastModifiedDate: ctx.timestamp,
    });
}
// Lobby block at L316-322 follows identical shape (createdDate: ts override)
```

Why NO-TOUCH: `updateWithAudit` hardcodes `lastModifiedDate: ctx.timestamp` and cannot express "set createdDate/lastSeenAt to a custom value `ts`". These are test-utility reducers that manipulate time on purpose. The Wave 2 File 2 (server.ts) plan must list L293-325 explicitly as out-of-scope.

Similar shape exists in the Lobby branch at L316-325 — same reasoning, same NO-TOUCH treatment.
