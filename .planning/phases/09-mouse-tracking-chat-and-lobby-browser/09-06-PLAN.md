**Create spacetimedb/src/reducers/draftClassic.ts:**

**1. start_draft reducer:**

Args: `lobbyId: t.u32()`

Logic:
- `getAuthenticatedUser(ctx)`, find lobby
- `ensureHostOrAbove(ctx, lobby, user)` — only host/admin/moderator can start
- `ensureStageIs(lobby, 'Waiting')`
- **Validation per D-29:** Get all LobbyMember rows for this lobby. Filter to Blue+Red team slots, exclude coaches (isCoach=true). Check all have `isConfirmed === true`. If any unconfirmed, throw `SenderError('All Blue and Red players must be confirmed before starting.')`.
- **Validate team composition:** Ensure at least 1 non-coach player on each team (Blue and Red). Throw if either team is empty.
- **Per D-43b validation:** If `lobby.autoRandomPick === true`, validate ALL Blue+Red players have an active HSR account with characters: for each player, find their active HsrAccount, check HsrAccountCharacter count > 0. Throw if any player lacks characters.
- **Build draft sequence:** If `lobby.draftMode.tag === 'Classic'`: `buildClassicSequence(lobby.banMode.tag)`. If `lobby.draftMode.tag === 'Auction'`: `buildAuctionBanSequence(lobby.banMode.tag)`.
- **Assign captains per D-30:** For each team (Blue, Red), if no player has isCaptain=true, set first non-coach player on that team as captain via delete+insert on LobbyMember.
- **Create MatchSession:** `{ lobbyId: lobby.id, turnIndex: 0, draftSequence: sequence, timerState: { turnStartAt: ctx.timestamp, teamBlueReserveMs: lobby.reserveBankSeconds * 1000, teamRedReserveMs: lobby.reserveBankSeconds * 1000, isPaused: false, accumulatedPauseMs: 0 }, isAuctionPhase: false, nextNominatorTeam: { tag: 'Blue', value: {} }, blueCharactersWon: 0, redCharactersWon: 0, currentNomination: undefined, currentBidAmount: undefined, currentBidTeam: { tag: 'Spectator', value: {} }, teamBlueCharBudget: lobby.characterBudget, teamRedCharBudget: lobby.characterBudget, teamBlueLcBudget: lobby.lightconeBudget, teamRedLcBudget: lobby.lightconeBudget, pausesUsedBlue: 0, pausesUsedRed: 0, ...auditInsert(ctx, user.id) }`
- **Create MatchResultRecord:** Per existing match result patterns. Set `matchType` from lobby.matchType, `tournamentId` from lobby.tournamentId, `bracketMatchId` from lobby.bracketMatchId, `refereeFullControl` based on referee's teamSlot per D-44. Set status to Pending.
- **Create MatchResultParticipant rows:** For each Blue+Red non-coach member, insert with `isCaptain` from LobbyMember.
- **Update lobby stage:** `{ tag: 'Drafting', value: {} }`, update `lastActivityAt`
- Insert system chat message: `'Draft has started!'`

**2. pick_character reducer:**

Args: `lobbyId: t.u32(), characterName: t.string(), eidolon: t.u8()`

Logic:
- `getAuthenticatedUser(ctx)`, find lobby, find session
- `ensureStageIs(lobby, 'Drafting')`
- `ensureLobbyMember(ctx, lobbyId, user.id)` — get member
- **D-39 Coach guard:** `if (member.isCoach) throw new SenderError('Coaches cannot perform draft actions.')`
- **Turn validation:** Get current step from `session.draftSequence[session.turnIndex]`. Verify `step.actionRequired.tag === 'Pick'`. Verify caller is on the correct team (`step.teamTurn.tag === member.teamSlot.tag`). If `member.isCaptain === false` and there IS a captain on the team, throw (only captain or sole player picks).
- **Character availability:** Check no prior MatchSessionStep in this lobby has picked this character (unless `lobby.allowMirrorPicks === true` per D-42). Get all steps: `[...ctx.db.MatchSessionStep.lobby_id.filter(lobbyId)]`, filter for `action.tag === 'Pick'` and `payload.value.characterName === characterName`. If found and `!lobby.allowMirrorPicks`, throw `SenderError('Character already picked.')`. Also check bans.
- **D-40 Ownership validation:** If `lobby.requireOwnership === true`, call `validateCharacterOwnership(ctx, user.id, characterName, lobbyId)`.
- **Determine cost:** Look up character cost from `HsrCharacterCost` table using (characterName, eidolon, costSetId, gameMode). If not found, cost = 0 (EMPTY CHARACTER at 0 cost per D-47).
- **Record step:** Insert MatchSessionStep with `{ lobbyId, sequence: session.turnIndex, actorUserId: user.id, actorSlot: member.teamSlot, action: { tag: 'Pick', value: {} }, payload: { tag: 'Pick', value: { characterName, eidolon, costPaid: cost } }, ...auditInsert(ctx, user.id) }`
- **Advance turn:** `session.turnIndex + 1`. If `turnIndex >= draftSequence.length`: if Classic mode and draft complete, transition to Equipping stage. If Auction mode and bans are done, set `isAuctionPhase: true`. Update MatchSession via `lobbyId.update()` (single PK).
- Update timer: `timerState.turnStartAt = ctx.timestamp`, reset `accumulatedPauseMs: 0`
- Update lobby `lastActivityAt`

**Create spacetimedb/src/reducers/draftControl.ts:**

**1. undo_last_step reducer (per D-60):**

Args: `lobbyId: t.u32()`

Logic:
- `getAuthenticatedUser(ctx)`, find lobby, find session
- `ensureStageIs(lobby, 'Drafting')`
- `ensureLobbyMember(ctx, lobbyId, user.id)` — get member
- Permission: `member.isReferee === true` and `lobby.refereeCanUndo === true`. If neither, throw `SenderError('Only referees with undo permission can undo.')`.
- Validation: `session.turnIndex === 0` throw `SenderError('No steps to undo.')`
- Find the last step: `[...ctx.db.MatchSessionStep.lobby_id.filter(lobbyId)]` sorted by sequence descending, take first. Delete it.
- Insert an Undo step: `{ lobbyId, sequence: session.turnIndex, actorUserId: user.id, actorSlot: member.teamSlot, action: { tag: 'Undo', value: {} }, payload: { tag: 'Undo', value: { originalSequenceId: session.turnIndex - 1 } }, ...auditInsert(ctx, user.id) }`
- Decrement turnIndex: update MatchSession with `turnIndex: session.turnIndex - 1`
- If session was in auction phase and the undone step brought it back to ban phase, set `isAuctionPhase: false`
- Reset timer: `timerState.turnStartAt = ctx.timestamp`

**2. pause_draft reducer (per D-61):**

Args: `lobbyId: t.u32()`

Logic:
- `getAuthenticatedUser(ctx)`, find lobby, find session
- `ensureStageIs(lobby, 'Drafting')`
- `ensureLobbyMember(ctx, lobbyId, user.id)`
- If `session.timerState.isPaused === true`: throw `SenderError('Draft is already paused.')`
- Permission check:
  - If member.isReferee and lobby.refereeCanPause: allowed (unlimited)
  - If NOT referee: check `lobby.allowPlayerPause === true` per D-33. Then enforce 3-per-team limit: if member on Blue team, check `session.pausesUsedBlue < 3`. If on Red, `session.pausesUsedRed < 3`. Throw if limit reached.
  - Spectators cannot pause.
- Calculate time remaining: `const elapsed = Number(ctx.timestamp.microsSinceUnixEpoch - session.timerState.turnStartAt.microsSinceUnixEpoch) / 1000; const timeRemainingMs = Math.max(0, (lobby.standardTurnSeconds * 1000) - elapsed + session.timerState.accumulatedPauseMs);`
- Insert Pause step: `{ ..., action: { tag: 'Pause', value: {} }, payload: { tag: 'Pause', value: { timeRemainingMs: Math.round(timeRemainingMs), isAutoPause: false } } }`
- Update session: `timerState.isPaused = true`. Increment pausesUsedBlue or pausesUsedRed (non-referee only).
- Update lobby `lastActivityAt`

**3. resume_draft reducer (per D-62):**

Args: `lobbyId: t.u32()`

Logic:
- `getAuthenticatedUser(ctx)`, find lobby, find session
- `ensureStageIs(lobby, 'Drafting')`
- If `session.timerState.isPaused === false`: throw `SenderError('Draft is not paused.')`
- Permission per D-62: referee OR the original pausing player can resume. Find the most recent Pause step, check if its actorUserId matches user.id OR if user is referee.
- Update session: `timerState.isPaused = false`, `timerState.turnStartAt = ctx.timestamp`, `timerState.accumulatedPauseMs = timeRemainingMs from the Pause step` (so the clock continues from where it was)
- Update lobby `lastActivityAt`
