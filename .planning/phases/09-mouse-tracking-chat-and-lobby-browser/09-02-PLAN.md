**Create spacetimedb/src/helpers/lobbyHelpers.ts:**

Export the following shared validation functions. All take `ctx` as first param and the user row as second. Use `SenderError` for user-facing errors (import from `spacetimedb/server`):

1. `ensureNotInLobby(ctx, userId: number): void` — Per D-22, check `[...ctx.db.LobbyMember.user_id.filter(userId)]`. If length > 0, throw `SenderError('You are already in a lobby. Leave it before creating or joining another.')`.

2. `ensureGuestRestrictions(user, matchType): void` — Per D-23, if `user.isGuest === true` and `matchType.tag === 'Ranked'`, throw `SenderError('Guests cannot create or join Ranked lobbies.')`. Also if `user.isGuest === true`, note guest roster visibility is enforced (ClosedNoRating) but this is applied at the lobby creation level, not here.

3. `ensureLobbyMember(ctx, lobbyId: number, userId: number)` — Returns the LobbyMember row or throws `SenderError('You are not a member of this lobby.')`. Use `[...ctx.db.LobbyMember.by_lobby_and_user.filter([lobbyId, userId])][0]`.

4. `ensureHostOrAbove(ctx, lobby, user)` — Checks if user is the lobby host (`lobby.hostUserId === user.id`) OR `isRoleAtLeast(user.role, 'Moderator')`. Throws `SenderError('Only the host, moderators, or admins can perform this action.')` if neither.

5. `ensureNotBanned(ctx, lobbyId: number, userId: number): void` — Check `[...ctx.db.LobbyBan.by_lobby_and_user.filter([lobbyId, userId])][0]`. If found, throw `SenderError('You are banned from this lobby.')`.

6. `ensureStageIs(lobby, ...stages: string[]): void` — Check `stages.includes(lobby.stage.tag)`. If not, throw `SenderError('This action is not allowed in the current lobby stage (' + lobby.stage.tag + ').')`.

7. `canKickOrBan(ctx, lobby, user, member): boolean` — Per D-21, returns true if user is host (`lobby.hostUserId === user.id`), `isRoleAtLeast(user.role, 'Admin')`, `isRoleAtLeast(user.role, 'Moderator')`, or (member.isReferee && lobby.refereeCanKick). Note the referee kick power check.

Import from ensurePermissions.ts: `getAuthenticatedUser`, `isRoleAtLeast`.

**Create spacetimedb/src/helpers/anonymousHelpers.ts (per D-69/D-70/D-71):**

Export `shouldAnonymize(ctx, lobbyId: number, targetUserId: number, lobby?: any): boolean`:

```typescript
export function shouldAnonymize(ctx: any, lobbyId: number, targetUserId: number, lobby?: any): boolean {
    if (!lobby) lobby = ctx.db.Lobby.id.find(lobbyId);
    if (!lobby) return false;
    if (!lobby.isAnonymousPlayers && !lobby.isAnonymousSpectators) return false;

    // Resolve caller
    const mapping = ctx.db.UserIdentity.identity.find(ctx.sender);
    if (!mapping) return false;
    const callerUserId = mapping.userId;

    // Never anonymize self
    if (callerUserId === targetUserId) return false;

    const callerMember = [...ctx.db.LobbyMember.by_lobby_and_user.filter([lobbyId, callerUserId])][0];
    const targetMember = [...ctx.db.LobbyMember.by_lobby_and_user.filter([lobbyId, targetUserId])][0];
    if (!callerMember || !targetMember) return false;

    // D-71: Spectator referee sees all real identities
    if (callerMember.isReferee && callerMember.teamSlot.tag === 'Spectator') return false;

    // D-70: Same team = real identities
    if (callerMember.teamSlot.tag === targetMember.teamSlot.tag) return false;

    // D-70: Spectators see all anonymized
    if (callerMember.teamSlot.tag === 'Spectator') return true;

    // Opponent on a team = anonymize based on lobby setting
    return lobby.isAnonymousPlayers;
}
```

**4. close_lobby reducer:**

Args: `lobbyId: t.u32()`

Logic:
- `getAuthenticatedUser(ctx)` for auth
- Find lobby by id, throw if not found
- `ensureHostOrAbove(ctx, lobby, user)` — host/admin/moderator
- `ensureStageIs(lobby, 'Waiting', 'Finished')` per D-20 — blocked during Drafting/Equipping/Scoring
- **Hard delete cascade per D-19:**
  1. Delete all ChatMessage rows: `for (const msg of [...ctx.db.ChatMessage.lobby_id.filter(lobbyId)]) { ctx.db.ChatMessage.id.delete(msg.id); }` (per CHAT-03)
  2. Delete all LobbyMember rows: `for (const member of [...ctx.db.LobbyMember.lobby_id.filter(lobbyId)]) { ctx.db.LobbyMember.by_lobby_and_user.delete([lobbyId, member.userId]); }`
  3. Delete all LobbyBan rows: `for (const ban of [...ctx.db.LobbyBan.lobby_id.filter(lobbyId)]) { ctx.db.LobbyBan.by_lobby_and_user.delete([lobbyId, ban.bannedUserId]); }`
  4. Delete LobbyPassword if exists: `const pw = ctx.db.LobbyPassword.lobbyId.find(lobbyId); if (pw) ctx.db.LobbyPassword.lobbyId.delete(lobbyId);`
  5. Delete all LobbyCursorEvent rows: `for (const evt of [...ctx.db.LobbyCursorEvent.lobby_id.filter(lobbyId)]) { ctx.db.LobbyCursorEvent.id.delete(evt.id); }`
  6. Delete MatchSession if exists: `const ms = ctx.db.MatchSession.lobbyId.find(lobbyId); if (ms) ctx.db.MatchSession.lobbyId.delete(lobbyId);`
  7. Delete all MatchSessionStep rows for this lobby
  8. Delete Lobby: `ctx.db.Lobby.id.delete(lobbyId)`

**5. kick_member reducer:**

Args: `lobbyId: t.u32(), targetUserId: t.u32()`

Logic:
- `getAuthenticatedUser(ctx)`, find lobby, find member (caller's own LobbyMember)
- Check `canKickOrBan(ctx, lobby, user, callerMember)` — throws if not permitted
- Cannot kick self: `if (targetUserId === user.id) throw new SenderError('Cannot kick yourself.')`
- Cannot kick host: `if (targetUserId === lobby.hostUserId) throw new SenderError('Cannot kick the host.')`
- Delete target's LobbyMember row
- Decrement `currentPlayerCount`
- Insert system message: `targetUser.displayName + ' was kicked from the lobby.'`

**6. ban_member reducer:**

Args: `lobbyId: t.u32(), targetUserId: t.u32()`

Logic:
- Same permission check as kick_member
- Cannot ban self or host
- Insert LobbyBan row: `{ lobbyId, bannedUserId: targetUserId, bannedByUserId: user.id, ...auditInsert(ctx, user.id) }`
- Delete target's LobbyMember row if they are currently a member
- Decrement `currentPlayerCount` if they were a member
- Insert system message: `targetUser.displayName + ' was banned from the lobby.'`
