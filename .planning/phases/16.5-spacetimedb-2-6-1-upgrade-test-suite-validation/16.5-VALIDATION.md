  definitive gate for the v2.6.1 optional-key codegen change (PR #4940). Green here = D-01 holds
  (zero application-code edits required).
- **After every task commit:** Run `npm run test:typecheck` then `npm test` (unit).
- **After the full upgrade wave:** Run `npm run test:all`.
- **Before `/gsd-verify-work`:** Full suite (`npm run test:all`) must be green under 2.6.1 with
  bindings regenerated by the upgraded toolchain.
- **Max feedback latency:** typecheck < 30s.
