### E2E Flows

**Player Registration -> Tournament -> Match -> Finalization:**
1. User registers via clientConnected (index.ts) -> UserIdentity + User created
2. User creates HSR account (roster.ts) -> HsrAccount + HsrAccountCharacter via rosterMutations.ts -> updateAccountRating
3. User registers for tournament (tournamentRegistration.ts) -> TournamentEnrolled + TournamentTeamMember + TournamentPlayerAccount
4. TO advances tournament stages (tournamentManagement.ts) -> stage transition guards (validateRegistrationToSeeding, validateSeedingToInProgress)
5. Bracket generated (bracketGeneration.ts) -> BracketMatch rows with FK links (two-pass wiring)
6. Tournament lobby created (tournamentLobby.ts) -> Lobby inherits ALL tournament settings + LobbyMember + LobbyMemberAccount
7. Draft starts (draftClassic.ts) -> MatchSession + MatchSessionStep + MatchResultRecord + MRP with accountRatingSnapshot captured via max-across-LMA
8. Match played -> MatchResultGame scores submitted (scoreEntry.ts) -> confirmed (matchResultSubmission.ts)
9. Match finalized (finalizationHelpers.ts runFinalization) -> 19-step pipeline:
   - History archived (steps 7-10), MMR processed from snapshot (step 11), stats incremented (steps 13-16), achievements checked (step 16.5), bracket advanced (step 17), ephemeral records deleted (step 18), lobby hard-deleted (step 19)
10. Bracket advances (bracketHelpers.ts) -> winner placed in next match; tournament MMR batch via process_tournament_mmr

All links verified end-to-end by integration checker. No broken flows detected.
