**Import block:**
```typescript
import spacetimedb from '../schema';
import { t, SenderError } from 'spacetimedb/server';
import { ensureVerifiedUser } from '../helpers/ensurePermissions';
import { auditInsert, auditUpdate } from '../helpers/auditColumns';
import { validateUid, deriveRegion, recalcDuplicateUid } from '../helpers/rosterHelpers';
```

**1. `create_hsr_account`** — params: `{ uid: t.string(), displayLabel: t.string() }`
- Call `ensureVerifiedUser(ctx)` to get user
- Call `validateUid(uid)` — throws if invalid
- Call `deriveRegion(uid)` to get region string
- Count existing accounts: `[...ctx.db.HsrAccount.hsr_account_user_id.filter(user.id)]`
- If `existing.length >= 5`, throw SenderError `'Maximum 5 HSR accounts per user'`
- Auto-default label: `const label = displayLabel.trim() || 'Account ' + (existing.length + 1);`
- First account auto-activates: `const isFirst = existing.length === 0;`
- Insert: `ctx.db.HsrAccount.insert({ id: 0, userId: user.id, uid, region, displayLabel: label, isActive: isFirst, isRosterPublic: false, isRatingPublic: false, isDuplicateUid: false, ...auditInsert(ctx, user.id) } as any);`
- Call `recalcDuplicateUid(ctx, uid, user.id)` to update flags across all accounts with this UID

**2. `update_hsr_account`** — params: `{ hsrAccountId: t.u32(), displayLabel: t.string(), isRosterPublic: t.bool(), isRatingPublic: t.bool() }`
- Call `ensureVerifiedUser(ctx)` to get user
- Find account: `ctx.db.HsrAccount.id.find(hsrAccountId)`
- If not found, throw `'HSR account not found'`
- If `account.userId !== user.id`, throw `'Not your account'`
- Validate displayLabel not empty after trim: if empty, throw `'Display label cannot be empty'`
- Update: `ctx.db.HsrAccount.id.update({ ...account, displayLabel: displayLabel.trim(), isRosterPublic, isRatingPublic, ...auditUpdate(ctx, account, user.id) });`
- Note: UID and region are immutable — this reducer does NOT accept them

**3. `set_active_hsr_account`** — params: `{ hsrAccountId: t.u32() }`
- Call `ensureVerifiedUser(ctx)` to get user
- Find account: `ctx.db.HsrAccount.id.find(hsrAccountId)`
- If not found, throw `'HSR account not found'`
- If `account.userId !== user.id`, throw `'Not your account'`
- If already active, return early (no-op)
- Deactivate all other accounts for this user:
  ```typescript
  const allAccounts = [...ctx.db.HsrAccount.hsr_account_user_id.filter(user.id)];
  for (const acc of allAccounts) {
      if (acc.isActive && acc.id !== hsrAccountId) {
          ctx.db.HsrAccount.id.update({ ...acc, isActive: false, ...auditUpdate(ctx, acc, user.id) });
      }
  }
  ```
- Activate the target: `ctx.db.HsrAccount.id.update({ ...account, isActive: true, ...auditUpdate(ctx, account, user.id) });`

**4. `delete_hsr_account`** — params: `{ hsrAccountId: t.u32() }`
- Call `ensureVerifiedUser(ctx)` to get user
- Find account: `ctx.db.HsrAccount.id.find(hsrAccountId)`
- If not found, throw `'HSR account not found'`
- If `account.userId !== user.id`, throw `'Not your account'`
- Save the UID before deletion for recalc: `const uid = account.uid;`
- Cascade delete all characters: `const characters = [...ctx.db.HsrAccountCharacter.hsr_acc_char_account_id.filter(hsrAccountId)]; for (const char of characters) { ctx.db.HsrAccountCharacter.delete(char); }`
- Delete the account: `ctx.db.HsrAccount.id.delete(hsrAccountId);`
- Auto-activate oldest remaining if this was the active account:
  ```typescript
  if (account.isActive) {
      const remaining = [...ctx.db.HsrAccount.hsr_account_user_id.filter(user.id)];
      if (remaining.length > 0) {
          remaining.sort((a: any, b: any) => Number(a.createdDate.microsSinceUnixEpoch - b.createdDate.microsSinceUnixEpoch));
          ctx.db.HsrAccount.id.update({ ...remaining[0], isActive: true, ...auditUpdate(ctx, remaining[0], user.id) });
      }
  }
  ```
- Call `recalcDuplicateUid(ctx, uid, user.id)` to update flags

**5. `batch_upsert_characters`** — params: `{ hsrAccountId: t.u32(), charactersJson: t.string() }`
- Call `ensureVerifiedUser(ctx)` to get user
- Find account, verify ownership (same pattern as above)
- Parse JSON: `const items: Array<{characterName: string, eidolonLevel: number}> = JSON.parse(charactersJson);`
- If not array or empty, throw `'charactersJson must be a non-empty JSON array'`
- **Phase 1 — Validate ALL before writing ANY:**
  ```typescript
  for (const item of items) {
      if (!ctx.db.HsrCharacter.name.find(item.characterName)) {
          throw new SenderError(`Invalid character: "${item.characterName}"`);
      }
      if (item.eidolonLevel === undefined || item.eidolonLevel < 0 || item.eidolonLevel > 6) {
          throw new SenderError(`Invalid eidolon level for "${item.characterName}": must be 0-6`);
      }
  }
  ```
- **Phase 2 — Upsert all:**
  ```typescript
  for (const item of items) {
      const existing = (ctx.db.HsrAccountCharacter as any).primaryKey.find({
          hsrAccountId, characterName: item.characterName
      });
      if (existing) {
          ctx.db.HsrAccountCharacter.delete(existing);
      }
      ctx.db.HsrAccountCharacter.insert({
          hsrAccountId,
          characterName: item.characterName,
          eidolonLevel: item.eidolonLevel,
          ...(existing ? auditUpdate(ctx, existing, user.id) : auditInsert(ctx, user.id)),
      } as any);
  }
  ```

**6. `batch_remove_characters`** — params: `{ hsrAccountId: t.u32(), characterNamesJson: t.string() }`
- Call `ensureVerifiedUser(ctx)` to get user
- Find account, verify ownership
- Parse JSON: `const names: string[] = JSON.parse(characterNamesJson);`
- If not array or empty, throw `'characterNamesJson must be a non-empty JSON array'`
- For each name, find via composite PK and delete:
  ```typescript
  for (const name of names) {
      const existing = (ctx.db.HsrAccountCharacter as any).primaryKey.find({
          hsrAccountId, characterName: name
      });
      if (!existing) {
          throw new SenderError(`Character "${name}" not found on this account`);
      }
  }
  // All validated — now delete
  for (const name of names) {
      const row = (ctx.db.HsrAccountCharacter as any).primaryKey.find({
          hsrAccountId, characterName: name
      });
      ctx.db.HsrAccountCharacter.delete(row);
  }
  ```

**7. `migrate_roster`** — params: `{ sourceAccountId: t.u32(), targetAccountId: t.u32(), mode: t.string() }`
- Call `ensureVerifiedUser(ctx)` to get user
- Validate mode: `if (mode !== 'copy' && mode !== 'move') throw new SenderError('Mode must be "copy" or "move"');`
- Find both accounts, verify both belong to user
- If sourceAccountId === targetAccountId, throw `'Source and target cannot be the same account'`
- Get source characters: `const sourceChars = [...ctx.db.HsrAccountCharacter.hsr_acc_char_account_id.filter(sourceAccountId)];`
- For each source character, upsert into target (overwrite eidolon level if exists):
  ```typescript
  for (const char of sourceChars) {
      const existingInTarget = (ctx.db.HsrAccountCharacter as any).primaryKey.find({
          hsrAccountId: targetAccountId, characterName: char.characterName
      });
      if (existingInTarget) { ctx.db.HsrAccountCharacter.delete(existingInTarget); }
      ctx.db.HsrAccountCharacter.insert({
          hsrAccountId: targetAccountId,
          characterName: char.characterName,
          eidolonLevel: char.eidolonLevel,
          ...(existingInTarget ? auditUpdate(ctx, existingInTarget, user.id) : auditInsert(ctx, user.id)),
      } as any);
  }
  ```
- If mode === 'move', delete all source characters:
  ```typescript
  if (mode === 'move') {
      for (const char of sourceChars) { ctx.db.HsrAccountCharacter.delete(char); }
  }
  ```

```markdown
# Roster Management — Architecture

## Overview

Players create HSR account entries (up to 5), add owned characters with eidolon levels,
control visibility, and migrate rosters between accounts. Admins can proxy all operations.
Archetype tagging enables frontend diversity scoring.

## Table Relationships

```

```
## Reducer Flows

### create_hsr_account(uid, displayLabel)
1. ensureVerifiedUser → validates non-guest
2. validateUid → 9-digit regex
3. deriveRegion → first digit maps to region
4. Check 5-account limit
5. Auto-default label if empty
6. First account auto-activates (isActive = true)
7. Insert HsrAccount
8. recalcDuplicateUid → updates isDuplicateUid for all accounts with same UID

### delete_hsr_account(hsrAccountId)
1. ensureVerifiedUser → ownership check
2. Cascade: delete all HsrAccountCharacter rows
3. Delete HsrAccount
4. If was active: auto-activate oldest remaining (sort by createdDate)
5. recalcDuplicateUid for the deleted UID

### batch_upsert_characters(hsrAccountId, charactersJson)
1. ensureVerifiedUser → ownership check
2. Parse JSON array of {characterName, eidolonLevel}
3. Phase 1: Validate ALL (character exists in HsrCharacter, eidolon 0-6)
4. Phase 2: Upsert ALL (composite PK find, delete+insert pattern)
5. Atomic: any validation failure rejects entire batch

### migrate_roster(sourceAccountId, targetAccountId, mode)
1. ensureVerifiedUser → both accounts belong to user
2. Copy mode: upsert source chars into target (overwrite eidolon)
3. Move mode: copy + delete source chars

## Visibility Rules

- isRosterPublic: controls whether other users see character roster
- isRatingPublic: controls whether other users see computed rating

- Rating = frontend-computed from character costs + archetype diversity

## Admin Proxy

- No ownership checks
- Audit trail uses admin.id

- Admin-managed via admin_upsert_archetype, admin_delete_archetype

- Used by frontend for horizontal diversity scoring
```
