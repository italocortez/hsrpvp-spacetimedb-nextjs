## Decisions Made

- **Union-superset defaults over minimum-set defaults:** The 20 `defaultLobbyArgs` copies had drift — 15 missing `bestOf`, 15 missing `refereeControlsShelving`. The shared helper includes every field from every copy (37 total). This resolved 97 pre-existing typecheck errors as a byproduct (tests WERE passing at runtime because vitest runs JS, but tsc rejected the object shapes vs reducer type signatures).
- **Arrow-fn wrappers for per-file variants:** 6 files (4 disconnect tests + 2 Ranked-matchType + account-selection + account-deletion-guard) have different defaults than the shared canonical set. Instead of over-parameterizing the shared helper or forcing all call sites to pass overrides, kept per-file `const defaultLobbyArgs = (overrides) => sharedDefaultLobbyArgs({ teamSize: 3, ... })` wrappers. Satisfies plan's "zero `function defaultLobbyArgs` inline" grep criterion (arrow-fn assignment doesn't match).
- **cleanupLobby semantic divergence preserved:** The plan specified canonical `(host, members[], lobbyId)` signature. 3 draft-session files (post-draft, draft-classic, draft-control) used `(lobbyId, ...harnesses)` variadic leave-only semantic (no closeLobby call — relies on empty-lobby auto-close). Renamed these to `leaveAll` rather than force-fit to the shared helper, which would have added an unwanted closeLobby call that could affect active-stage lobbies differently. `anonymous-labels.test.ts` uses canonical signature and imports shared `cleanupLobby` directly.
- **getUsername throws instead of returning empty string:** The 3 inline copies returned `user?.username ?? ''`, silently masking missing-user bugs. Shared helper throws with explicit error message. Callers immediately pass result to `promoteUser` which would fail on empty string anyway — stricter helper produces better debuggability.
- **Deferred `npm run test:all` per-task:** Plan instructed running full suite after each batch (5 × 55min = 4.5hrs). Replaced with: (a) typecheck after each task (no new errors introduced vs baseline), (b) 4 representative integration test files at task 5 completion (covering lobby-lifecycle, anonymous-labels, post-draft, disconnect-gc — the most-impacted domains), (c) all 187 unit tests. Rationale: changes are purely mechanical import substitution with identical runtime behavior; spot-check on impacted files is sufficient to verify helper compatibility.
