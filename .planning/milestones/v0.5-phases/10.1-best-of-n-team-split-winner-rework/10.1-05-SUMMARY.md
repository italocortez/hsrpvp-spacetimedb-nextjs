All new series management features are live: best-of-N series reducers, tournament check-in, BetweenGames/Shelved awareness across GC/lifecycle/concede, and the full ParticipantStatus lifecycle wired into tournament stage transitions.

## What Was Built

### New Reducers

**seriesManagement.ts** (3 reducers):
- `advance_to_next_game`: D-07 authority, BetweenGames pre-condition, deletes current MatchSessionStep rows, resets MatchSession (turnIndex=0, budgets from lobby config, draftSequence=[], increments currentGameNumber), transitions BetweenGames -> Drafting
- `shelve_series`: D-07 authority, BetweenGames pre-condition, transitions BetweenGames -> Shelved
- `resume_series`: D-07 authority, Shelved pre-condition, unshelve gate (1+ non-coach/non-spectator per team present), transitions Shelved -> BetweenGames

**tournamentCheckIn.ts** (1 reducer):
- `check_in_tournament`: validates CheckIn stage, validates Registered status, updates to CheckedIn (delete+re-insert for composite PK)

### Modified Files

**postDraft.ts** — series-aware advance_stage from Scoring:
- When `seriesBestOf > 1`: reads MatchResultGame rows to count wins per side, updates gamesWonBlue/gamesWonRed on MatchSession, then routes to BetweenGames or AwaitingResult based on win condition
- When `seriesBestOf = 1`: existing behavior — goes directly to AwaitingResult

**lobbyLifecycle.ts**:
- `create_lobby`: accepts `bestOf` (u8, 0=default=1) and `refereeControlsShelving` (bool) params
- `join_lobby`: reconnect stages now include BetweenGames and Shelved
- `leave_lobby`: BetweenGames added to activeStages; Shelved exemption prevents auto-close on empty

**tournamentLobby.ts**:
- `create_tournament_lobby`: copies `BracketMatch.bestOf` to `Lobby.bestOf`; sets `refereeControlsShelving: true`

**finalizationHelpers.ts** — Step 8:
- MatchSessionStepHistory inserts now include `gameNumber: step.gameNumber ?? 1` (required for PK [matchHistoryId, gameNumber, sequence])

**lobbyGc.ts**:
- Shelved tournament lobbies: skipped entirely (persist until cancel_tournament)
- Casual Shelved lobbies: 72h TTL based on lastActivityAt
- BetweenGames: same all-offline + 30min rule as active stages

**concede.ts**:
- `concede_match`, `claim_forfeit`, `defer_match`: all have BetweenGames added to activeStages

**tournamentManagement.ts**:
- `advance_tournament_stage`: CheckIn->Seeding calls `removeUncheckedInParticipants`; Seeding->InProgress bulk-updates Registered/CheckedIn to Active

**tournamentHelpers.ts**:
- `STAGE_ORDER`: now includes CheckIn between Registration and Seeding
- `validateStageTransition`: allows Registration->Seeding skip (when checkInEnabled=false)
- `cascadeCleanupTournament`: hard-deletes Shelved/BetweenGames lobbies via `Lobby.bracket_match_id.filter()` indexed lookup BEFORE deleting bracket matches; uses GroupPhaseRecord (not old GroupStanding)
- New `removeUncheckedInParticipants`: handles captain transfer and team deletion for unchecked-in participants
- `validateSeedingToInProgress`: uses GroupPhaseRecord (fixes Plan 01 rename)

**index.ts**:
- Exports: `advance_to_next_game`, `shelve_series`, `resume_series` from seriesManagement
- Exports: `check_in_tournament` from tournamentCheckIn
