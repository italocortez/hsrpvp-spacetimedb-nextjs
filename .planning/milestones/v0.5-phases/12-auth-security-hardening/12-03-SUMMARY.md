## Decisions Made

- **A1 assumption failed**: `spacetime generate` does not emit client types for views (only tables). Strategy B (User table fallback) is the production path. Added `view_my_identity` subscription alongside `view_my_profile` to enable userId resolution for verified users who changed their username.
- **verifyIdentityFromToken WR-02**: onDisconnect handler rejects promise immediately (fail-fast) instead of waiting for 5s timeout, preventing connection pool exhaustion.
- **SEC-04 manual-only**: Integration tests cannot call a Next.js API route — SEC-04 must be verified in Task 4 human checkpoint by actually linking Discord.
- **UserManager Discord column**: Shows 'Linked'/'-' using `user.hasDiscordLinked`. Actual Discord usernames require a separate admin view (view_admin_user_private) which is out of scope for this plan.
