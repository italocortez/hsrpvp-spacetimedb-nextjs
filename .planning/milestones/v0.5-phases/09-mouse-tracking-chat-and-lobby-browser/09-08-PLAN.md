**Change 6 (D-91): Add revealTournamentHistory helper to finalizationHelpers.ts:**

Export a new helper function:
```typescript
export function revealTournamentHistory(ctx: any, tournamentId: number): void {
    // Find all MatchSessionHistory records associated with this tournament.
    // Tournament lobbies have isTournamentControlled=true and a tournamentId on the Lobby.
    // But at this point lobbies may be GC'd. Instead, use MatchResultRecord which has tournamentId.
    // Iterate MatchResultRecord where tournamentId matches, get their matchSessionHistory records.
    const matchResults = [...ctx.db.MatchResultRecord.tournament_id.filter(tournamentId)];
    for (const mr of matchResults) {
        // Find the associated MatchSessionHistory by lobbyId
        const histories = [...ctx.db.MatchSessionHistory.lobby_id.filter(mr.lobbyId)];
        for (const history of histories) {
            if (!history.isPubliclyVisible) {
                ctx.db.MatchSessionHistory.id.update({
                    ...history,
                    isPubliclyVisible: true,
                });
            }
        }
    }
}
```

Note: The exact index to use depends on what indexes exist on MatchResultRecord and MatchSessionHistory. The executor should check available indexes and adjust the lookup pattern accordingly. If no tournament_id index exists on MatchResultRecord, iterate all and filter. If MatchSessionHistory has no lobby_id index, use the available primary key or other index.
