**Create spacetimedb/src/reducers/draftAuction.ts:**

All 4 reducers share common validation: auth, lobby stage (Drafting), isAuctionPhase must be true, coach guard (D-39), member on correct team.

Shared helper function `getPickedCharacters(ctx, lobbyId): Set<string>` — returns set of character names already picked (via AuctionSold steps) for exclusivity check. Auction characters are ALWAYS exclusive (D-42: "Auction characters are always exclusive").

**1. nominate_character reducer (per D-47/D-48/D-53):**

Args: `lobbyId: t.u32(), characterName: t.string(), eidolon: t.u8()`

Logic:
- Auth, lobby, session, member checks. Coach guard.
- `if (!session.isAuctionPhase) throw new SenderError('Auction phase not active.')`
- `if (session.currentNomination) throw new SenderError('An auction is already in progress.')`
- Turn check: `session.nextNominatorTeam.tag === member.teamSlot.tag` — only the nominating team can nominate
- If member.isCaptain === false and there IS a captain on the team, throw (only captain or sole player nominates)
- Character availability: check not in picked set, not banned
- Per D-53: Look up base cost from HsrCharacterCost using (characterName, eidolon, lobby.costSetId, lobby.gameMode). If not found, base cost = 0 (0-cost characters per D-54).
- Budget check: nominating team must have enough characterBudget. If `member.teamSlot.tag === 'Blue'`: `if (baseCost > session.teamBlueCharBudget) throw new SenderError('Not enough budget to nominate this character.')`
- Per D-47: Nomination = automatic first bid at base cost. Set auction state on session:
  - `currentNomination: characterName`
  - `currentBidAmount: baseCost`
  - `currentBidTeam: member.teamSlot` (nominating team is first bidder)
- Insert Nominate step: `{ ..., action: { tag: 'Nominate', value: {} }, payload: { tag: 'Nominate', value: { characterName, eidolon } } }`
- Reset timer: `timerState.turnStartAt = ctx.timestamp`
- Update session via `lobbyId.update()`

**2. place_bid reducer (per D-48/D-53):**

Args: `lobbyId: t.u32(), bidAmount: t.f32()`

Logic:
- Auth, lobby, session, member checks. Coach guard.
- `if (!session.currentNomination) throw new SenderError('No auction in progress.')`
- Team check: bidder must be on the OPPOSITE team from `session.currentBidTeam` (alternating bids per D-48)
- Per D-53: Minimum raise: `if (bidAmount < session.currentBidAmount + lobby.minimumBidRaise) throw new SenderError('Bid must be at least ' + (session.currentBidAmount + lobby.minimumBidRaise))`
- Budget check: bidder team's remaining budget. If bidding team is Blue: `if (bidAmount > session.teamBlueCharBudget) throw new SenderError('Exceeds budget.')`. Same for Red.
- Insert Bid step: `{ ..., action: { tag: 'Bid', value: {} }, payload: { tag: 'Bid', value: { amount: bidAmount, targetCharacter: session.currentNomination } } }`
- Update session: `currentBidAmount: bidAmount, currentBidTeam: member.teamSlot`
- Reset timer

**3. pass_bid reducer (per D-48, resolves auction):**

Args: `lobbyId: t.u32()`

Logic:
- Auth, lobby, session, member checks. Coach guard.
- `if (!session.currentNomination) throw new SenderError('No auction in progress.')`
- Team check: passer must be on the team that is expected to bid next (opposite of currentBidTeam). This means the other team declines to outbid.
- **Resolution:** The `currentBidTeam` wins the character at `currentBidAmount`.
- Look up character eidolon from the original Nominate step (find the Nominate step in MatchSessionStep for this nomination)
- Insert AuctionSold step: `{ ..., action: { tag: 'AuctionSold', value: {} }, payload: { tag: 'AuctionSold', value: { characterName: session.currentNomination, winningAmount: session.currentBidAmount, winningTeam: session.currentBidTeam, eidolon } } }`
- **Deduct budget:** If winning team is Blue: `teamBlueCharBudget -= session.currentBidAmount`. Same for Red.
- **Increment characters won:** If Blue won: `blueCharactersWon += 1`. Same for Red.
- **Steal-skip logic per D-46:** Determine next nominator:
  - Normal: teams alternate nominations. If Blue nominated and Blue won: Red nominates next. If Blue nominated and Red won (steal): Blue nominates again (Red's turn was "spent" by winning).
  - Implementation: track which team nominated (find the Nominate step). If nominating team === winning team: next nominator is opposite team. If nominating team !== winning team (steal): next nominator stays as nominating team.
- **Clear auction state:** `currentNomination: undefined, currentBidAmount: undefined, currentBidTeam: { tag: 'Spectator', value: {} }`
- **Check auction end:** Per D-48, each team gets 8 characters (for teamSize=1, 8 characters per team). If `blueCharactersWon >= 8 && redCharactersWon >= 8` (or both teams have reached `8 * lobby.teamSize`): auction complete. Transition to Equipping stage.
- **Budget exhaustion check:** If next nominator team has 0 budget remaining AND the cheapest available character costs > 0: auto-pass nomination (nominate EMPTY CHARACTER at 0 cost). Or check if ANY character is affordable. If not, that team auto-nominates EMPTY at 0 cost.
- Reset timer, update session

**4. timer_expiry_auction reducer (per D-43):**

Args: `lobbyId: t.u32()`

Logic:
- Auth, lobby, session checks
- If in nomination phase (no currentNomination): auto-nominate EMPTY CHARACTER per D-43
- If in bidding phase (currentNomination exists): auto-pass for the expected bidding team per D-43
- Follow same logic as nominate_character or pass_bid respectively
