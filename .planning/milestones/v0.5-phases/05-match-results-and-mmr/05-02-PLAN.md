**1. Create `spacetimedb/src/helpers/eloCalculation.ts` -- Pure ELO math functions (no ctx.db access):**

All functions take plain numbers as input and return plain numbers. This file has ZERO database access -- it is purely mathematical. This keeps it testable and deterministic.

```typescript
// Type for config values passed in from EloConfigTable row
export interface EloConfigValues {
    kFactorNew: number;
    kFactorMid: number;
    kFactorVet: number;
    newThreshold: number;
    midThreshold: number;
    initialRating: number;
    sizeBonus: number;
    spreadDivisor: number;
    maxAccountBonus: number;
}
```

**`getKFactor(matchesPlayed: number, config: EloConfigValues): number`**
Per D-14:
- If matchesPlayed <= config.newThreshold (20): return config.kFactorNew (40)
- If matchesPlayed <= config.midThreshold (100): return config.kFactorMid (20)
- Else: return config.kFactorVet (10)

**`calculateExpectedScore(playerEffective: number, opponentEffective: number): number`**
Per D-15:
```
return 1 / (1 + Math.pow(10, (opponentEffective - playerEffective) / 400));
```

**`calculateRatingChange(kFactor: number, actualResult: number, expectedScore: number): number`**
Per D-15:
```
return Math.round(kFactor * (actualResult - expectedScore));
```
Returns a signed integer (positive for gain, negative for loss). Use Math.round to produce integer deltas.

**`calculateTeamEffective(teamRatings: number[], sizeBonus: number, spreadDivisor: number): number`**
Per D-18 through D-20:
```
const avg = teamRatings.reduce((a, b) => a + b, 0) / teamRatings.length;
if (teamRatings.length === 1) return avg;  // No modifier for solo
const stdev = Math.sqrt(
    teamRatings.reduce((sum, r) => sum + (r - avg) ** 2, 0) / teamRatings.length
);
return Math.round(avg + sizeBonus * (teamRatings.length - 1) - stdev / spreadDivisor);
```

**`calculateAccountModifier(higherAccountRating: number, lowerAccountRating: number, maxAccountBonus: number): number`**
Per D-24:
```
const gap = Math.abs(higherAccountRating - lowerAccountRating);
return Math.round((gap / 1000) * maxAccountBonus);
```
Returns the modifier to add to the higher-account-rating side's effective rating.

**2. Create `spacetimedb/src/helpers/statsIncrement.ts` -- PlayerStat and PlayerRelationship helpers:**

Both functions access ctx.db to read/write stat tables. They follow the composite PK delete+insert upsert pattern established in the codebase.

**`incrementPlayerStat(ctx: any, userId: number, gameMode: any, draftMode: any, isWin: boolean, isDraw: boolean, actingUserId: number): void`**
- Look up existing: `[...ctx.db.PlayerStat.by_user_mode_draft.filter([userId, gameMode, draftMode])][0]`
- If exists: delete + insert with incremented fields:
  - `matchesPlayed: existing.matchesPlayed + 1`
  - `wins: existing.wins + (isWin ? 1 : 0)`
  - `losses: existing.losses + (!isWin && !isDraw ? 1 : 0)`
  - `draws: existing.draws + (isDraw ? 1 : 0)`
  - `matchesSpectated: existing.matchesSpectated` (unchanged)
  - Preserve existing audit created* via `auditUpdate(ctx, existing, actingUserId)`
- If not exists: insert new row with initial values (matchesPlayed=1, wins/losses/draws as appropriate, matchesSpectated=0) via `auditInsert(ctx, actingUserId)`

**`incrementPlayerRelationship(ctx: any, userId: number, otherUserId: number, gameMode: any, draftMode: any, isAlly: boolean, didWin: boolean, actingUserId: number): void`**
- Look up existing: `[...ctx.db.PlayerRelationship.by_user_and_other_mode_draft.filter([userId, otherUserId, gameMode, draftMode])][0]`
- If exists: delete + insert with incremented fields based on isAlly:
  - If isAlly: `matchesAsAlly + 1`, `winsAsAlly + (didWin ? 1 : 0)`, opponent fields unchanged
  - If opponent: `matchesAsOpponent + 1`, `winsAsOpponent + (didWin ? 1 : 0)`, ally fields unchanged
  - Preserve existing audit created* via `auditUpdate(ctx, existing, actingUserId)`
- If not exists: insert new row with isAlly or isOpponent initial values (1 match, 0/1 wins) via `auditInsert(ctx, actingUserId)`

NOTE: PlayerRelationship is directional. For a pair (A, B), you must call this TWICE: once for userId=A, otherUserId=B, and once for userId=B, otherUserId=A. The finalization reducer handles this double-call.

**3. Create `spacetimedb/src/helpers/leaderboardRebuild.ts` -- Materialized leaderboard rebuild:**

**`rebuildLeaderboard(ctx: any, actingUserId: number): void`**

Per D-44 through D-49:
1. Delete ALL existing Leaderboard rows: `for (const row of [...ctx.db.Leaderboard.iter()]) { ctx.db.Leaderboard.delete(row); }`
2. Define categories as an array mapping: `[{category: 'MemoryOfChaos', gameModeTag: 'MemoryOfChaos'}, {category: 'ApocalypticShadow', gameModeTag: 'ApocalypticShadow'}, {category: 'AnomalyArbitration', gameModeTag: 'AnomalyArbitration'}]`
3. For each per-mode category:
   - Collect all MmrRating rows for this game mode: iterate `ctx.db.MmrRating.iter()` and filter where `row.gameMode.tag === gameModeTag && row.matchesPlayed >= 2` (per D-46, minimum 2 matches)
   - Sort by rating descending: `entries.sort((a, b) => b.rating - a.rating)`
   - Take top 100: `entries.slice(0, 100)`
   - For each entry, look up wins from PlayerStat: Sum wins across all draftModes for this userId and gameMode: `[...ctx.db.PlayerStat.by_user.filter(entry.userId)].filter(s => s.gameMode.tag === gameModeTag).reduce((sum, s) => sum + s.wins, 0)`
   - Insert Leaderboard row: `{ category, rank: index + 1, userId: entry.userId, rating: entry.rating, matchesPlayed: entry.matchesPlayed, wins, seasonId: entry.seasonId, ...auditInsert(ctx, actingUserId) }`
4. For the Global category:
   - Collect all unique userIds that have any MmrRating row with matchesPlayed >= 2
   - For each user, read their globalCompositeRating from any of their MmrRating rows (it's the same across all their rows since we update all of them). Use: `[...ctx.db.MmrRating.user_id.filter(userId)][0]?.globalCompositeRating ?? 0`
   - Also compute total matchesPlayed: sum matchesPlayed across all their MmrRating rows
   - And total wins: sum wins from PlayerStat across all modes for this user
   - Filter: only include users where globalCompositeRating > 0
   - Sort by globalCompositeRating descending
   - Take top 100, insert Leaderboard rows with category="Global"

NOTE on performance: This iterates MmrRating (expected ~300 rows at 100 users * 3 modes) and PlayerStat (expected ~600 rows). Acceptable for inline execution in a reducer transaction. At scale (500+ users), this should be reconsidered.

**Internal helper: `processMatchMmr(ctx, matchResult, participants, gameMode, matchHistoryId, actingUserId): void`**

Implementation per the flow in docs/mmr/architecture.md:

1. Read EloConfig: `const config = ctx.db.EloConfigTable.id.find(1)`. Throw `'ELO config not initialized. Call admin_seed_elo_config first.'` if missing.
2. Convert config to EloConfigValues interface: `const cv: EloConfigValues = { kFactorNew: config.kFactorNew, ... }`
3. Separate participants by team: `const blueParticipants = participants.filter(p => p.teamSide.tag === 'Blue')`, same for Red.
4. For each participant, get or create MmrRating:
   ```
   function getOrCreateRating(ctx, userId, gameMode, initialRating, actingUserId) {
       const existing = [...ctx.db.MmrRating.by_user_and_mode.filter([userId, gameMode])][0];
       if (existing) return existing;
       // Create new rating row for first-time ranked player
       const newRow = { userId, gameMode, rating: initialRating, matchesPlayed: 0, globalCompositeRating: undefined, seasonId: undefined, ...auditInsert(ctx, actingUserId) };
       ctx.db.MmrRating.insert(newRow as any);
       return { ...newRow };
   }
   ```
   (Per Research Pitfall 6: handle new players who have no MmrRating row yet.)

5. Collect team ratings arrays: `blueRatings = blueParticipants.map(p => getOrCreateRating(...).rating)`
6. Calculate team effective ratings per D-18:
   ```
   const blueEffective = calculateTeamEffective(blueRatings, cv.sizeBonus, cv.spreadDivisor);
   const redEffective = calculateTeamEffective(redRatings, cv.sizeBonus, cv.spreadDivisor);
   ```
7. Apply account rating modifier per D-22 through D-28 (always Fair MMR for Phase 5 -- Handicap Play choice tracking deferred to Phase 9/10 per D-23):
   - For each participant, get their active HsrAccount's accountRating: `[...ctx.db.HsrAccount.user_id.filter(userId)].find(a => a.isActive)?.accountRating ?? 0`
   - Calculate team average account ratings: `blueAvgAccount = avg of blue accounts`, `redAvgAccount = avg of red accounts`
   - If blueAvgAccount > redAvgAccount: `blueEffective += calculateAccountModifier(blueAvgAccount, redAvgAccount, cv.maxAccountBonus)` (per D-24, modifier added to higher-account side)
   - If redAvgAccount > blueAvgAccount: `redEffective += calculateAccountModifier(redAvgAccount, blueAvgAccount, cv.maxAccountBonus)`
   - If equal: no modifier

8. Determine actual result:
   - If matchResult.winnerUserId is undefined: draw (actualResult = 0.5 for all)
   - Else: find the winner's teamSide from participants. If winner is Blue: blueResult=1, redResult=0. If Red: blueResult=0, redResult=1.

9. For each participant, calculate and apply rating change:
   ```
   const playerRating = getOrCreateRating(ctx, participant.userId, gameMode, cv.initialRating, actingUserId);
   const isBlue = participant.teamSide.tag === 'Blue';
   const playerEffective = isBlue ? blueEffective : redEffective;
   const opponentEffective = isBlue ? redEffective : blueEffective;
   const expected = calculateExpectedScore(playerEffective, opponentEffective);
   const k = getKFactor(playerRating.matchesPlayed, cv);
   const actualResult = isBlue ? blueActualResult : redActualResult;
   const delta = calculateRatingChange(k, actualResult, expected);
   const newRating = Math.max(0, playerRating.rating + delta);  // Floor at 0
   ```

10. Update MmrRating (delete + insert for composite PK):
    ```
    // Re-read to get latest (may have been created in step 4)
    const currentRating = [...ctx.db.MmrRating.by_user_and_mode.filter([participant.userId, gameMode])][0];
    ctx.db.MmrRating.delete(currentRating);
    ctx.db.MmrRating.insert({
        userId: participant.userId,
        gameMode,
        rating: newRating,
        matchesPlayed: currentRating.matchesPlayed + 1,
        globalCompositeRating: currentRating.globalCompositeRating,  // Updated below
        seasonId: currentRating.seasonId,
        ...auditUpdate(ctx, currentRating, actingUserId),
    } as any);
    ```

11. Update globalCompositeRating for this player (per D-17, Research Pitfall 7):
    ```
    const allRatings = [...ctx.db.MmrRating.user_id.filter(participant.userId)];
    if (allRatings.length > 0) {
        const avgRating = Math.round(allRatings.reduce((sum, r) => sum + r.rating, 0) / allRatings.length);
        for (const r of allRatings) {
            ctx.db.MmrRating.delete(r);
            ctx.db.MmrRating.insert({
                ...r,
                globalCompositeRating: avgRating,
                ...auditUpdate(ctx, r, actingUserId),
            } as any);
        }
    }
    ```

12. Insert MmrHistory row per participant (per MMR-04):
    ```
    ctx.db.MmrHistory.insert({
        id: 0,  // autoInc
        userId: participant.userId,
        gameMode,
        matchHistoryId,
        previousRating: playerRating.rating,
        newRating,
        delta,
        seasonId: currentRating.seasonId,
        ...auditInsert(ctx, actingUserId),
    } as any);
    ```

**`finalize_match_result` reducer:**

Per D-09, D-10, D-11 finalization paths. Permission: Admin/Mod or the referee who submitted the result.

Reducer args: `{ matchResultId: t.u32() }`

Implementation:
1. `const user = getAuthenticatedUser(ctx)`
2. Find MatchResultRecord: `ctx.db.MatchResultRecord.id.find(matchResultId)`. Throw if missing.
3. Verify status is Validated: throw `'Match result must be Validated before finalization.'` if not.
4. For Ranked matches (per D-10): verify `mmrProcessedAt` is set (not undefined). Throw `'Ranked match must have MMR processed before finalization. Call process_tournament_mmr for tournament matches.'` if not.
   - Exception: for non-tournament Ranked matches (`!matchResult.isTournamentControlled`), process MMR INLINE here (standalone ranked path per D-10): call `processMatchMmr(...)` and then stamp mmrProcessedAt.
5. For Casual matches (per D-09): skip MMR gate entirely. mmrProcessedAt stays undefined.
6. Verify caller has authority: `isRoleAtLeast(user.role, 'Moderator')` OR `matchResult.refereeUserId === user.id` OR (for tournament matches) ensureTournamentAccess succeeds. Throw `'You do not have authority to finalize this match result.'` if none.
7. Read all related data:
   - `const participants = [...ctx.db.MatchResultParticipant.match_result_id.filter(matchResultId)]`
   - `const games = [...ctx.db.MatchResultGame.match_result_id.filter(matchResultId)]`
   - `const lobby = ctx.db.Lobby.id.find(matchResult.lobbyId)` -- needed for history snapshot
8. Determine match outcome: if winnerUserId is undefined -> `{ tag: 'Draw', value: {} }`. Else find winner's teamSide from participants: Blue -> `{ tag: 'BlueWins', value: {} }`, Red -> `{ tag: 'RedWins', value: {} }`.
9. Write MatchSessionHistory row:
   ```
   const historyRow = ctx.db.MatchSessionHistory.insert({
       id: 0,  // autoInc
       lobbyCode: lobby ? lobby.joinCode : 'UNKNOWN',
       playedAt: matchResult.createdDate,
       draftMode: lobby ? lobby.draftMode : { tag: 'Classic', value: {} },
       gameMode: lobby ? lobby.gameMode : games[0]?.gameMode ?? { tag: 'MemoryOfChaos', value: {} },
       teamBlueAlias: lobby ? lobby.teamBlueAlias : 'Blue',
       teamRedAlias: lobby ? lobby.teamRedAlias : 'Red',
       snapshotConfig: lobby ? {
           teamSize: lobby.teamSize,
           draftMode: lobby.draftMode,
           banMode: lobby.banMode,
           standardTurnSeconds: lobby.standardTurnSeconds,
           reserveBankSeconds: lobby.reserveBankSeconds,
           auctionBudget: lobby.auctionBudget,
           rosterDiffAdvantage: lobby.rosterDiffAdvantage,
           rosterThreshold: lobby.rosterThreshold,
           underThresholdAdvantage: lobby.underThresholdAdvantage,
           aboveThresholdPenalty: lobby.aboveThresholdPenalty,
           deathPenalty: lobby.deathPenalty,
       } : { teamSize: 1, draftMode: { tag: 'Classic', value: {} }, banMode: { tag: 'None', value: {} }, standardTurnSeconds: 60, reserveBankSeconds: 120, auctionBudget: undefined, rosterDiffAdvantage: 0, rosterThreshold: 0, underThresholdAdvantage: 0, aboveThresholdPenalty: 0, deathPenalty: 0 },
       outcome: matchOutcome,
       rosterBlue: '[]',  // Roster snapshot deferred -- would need MatchSessionStep data
       rosterRed: '[]',
       ...auditInsert(ctx, user.id),
   } as any);
   ```
   NOTE: The returned insert value has the autoInc `id` assigned. Store it for matchHistoryId.
   IMPORTANT: SpacetimeDB insert returns the inserted row. Capture it: `const historyRow = ctx.db.MatchSessionHistory.insert(...)`. Use `historyRow.id` as matchHistoryId.

10. For standalone Ranked matches (not tournament controlled): process MMR inline:
    ```
    if (matchResult.matchType.tag === 'Ranked' && !matchResult.isTournamentControlled) {
        processMatchMmr(ctx, matchResult, participants, lobby?.gameMode ?? games[0]?.gameMode, historyRow.id, user.id);
        // Stamp mmrProcessedAt
        const freshResult = ctx.db.MatchResultRecord.id.find(matchResultId)!;
        ctx.db.MatchResultRecord.id.update({
            ...freshResult,
            mmrProcessedAt: ctx.timestamp,
            ...auditUpdate(ctx, freshResult, user.id),
        } as any);
        // Rebuild leaderboard after MMR processing
        rebuildLeaderboard(ctx, user.id);
    }
    ```

11. For tournament batch path: update MmrHistory rows that have sentinel matchHistoryId=0.
    When process_tournament_mmr runs first, it inserts MmrHistory rows with matchHistoryId=0 (sentinel) because history hasn't been written yet. Now that we've written MatchSessionHistory (step 9), back-fill those sentinel rows with the real matchHistoryId:
    ```
    if (matchResult.isTournamentControlled && matchResult.mmrProcessedAt !== undefined) {
        const participantUserIds = new Set(participants.map(p => p.userId));
        for (const uid of participantUserIds) {
            const mmrRows = [...ctx.db.MmrHistory.user_id.filter(uid)]
                .filter(h => h.matchHistoryId === 0);
            // Only update the most recent one per user (latest ID) for this match
            if (mmrRows.length > 0) {
                const latest = mmrRows.sort((a, b) => b.id - a.id)[0];
                ctx.db.MmrHistory.id.update({
                    ...latest,
                    matchHistoryId: historyRow.id,
                    ...auditUpdate(ctx, latest, user.id),
                } as any);
            }
        }
    }
    ```

12. Write MatchParticipantHistory per participant:
    ```
    for (const p of participants) {
        ctx.db.MatchParticipantHistory.insert({
            userId: p.userId,
            matchHistoryId: historyRow.id,
            teamSide: p.teamSide,
            ...auditInsert(ctx, user.id),
        } as any);
    }
    ```

13. Increment PlayerStat per participant:
    ```
    const gameMode = lobby?.gameMode ?? games[0]?.gameMode ?? { tag: 'MemoryOfChaos', value: {} };
    const draftMode = lobby?.draftMode ?? { tag: 'Classic', value: {} };
    for (const p of participants) {
        let participantWon = false;
        if (matchResult.winnerUserId !== undefined) {
            const winnerParticipant = participants.find(wp => wp.userId === matchResult.winnerUserId);
            participantWon = winnerParticipant ? winnerParticipant.teamSide.tag === p.teamSide.tag : false;
        }
        const isDraw = matchResult.winnerUserId === undefined;
        incrementPlayerStat(ctx, p.userId, gameMode, draftMode, participantWon, isDraw, user.id);
    }
    ```

14. Increment PlayerRelationship per participant pair:
    ```
    for (let i = 0; i < participants.length; i++) {
        for (let j = i + 1; j < participants.length; j++) {
            const a = participants[i];
            const b = participants[j];
            const isAlly = a.teamSide.tag === b.teamSide.tag;
            let aWon = false;
            let bWon = false;
            if (matchResult.winnerUserId !== undefined) {
                const winnerP = participants.find(wp => wp.userId === matchResult.winnerUserId);
                aWon = winnerP ? winnerP.teamSide.tag === a.teamSide.tag : false;
                bWon = winnerP ? winnerP.teamSide.tag === b.teamSide.tag : false;
            }
            // Bidirectional: A -> B and B -> A
            incrementPlayerRelationship(ctx, a.userId, b.userId, gameMode, draftMode, isAlly, aWon, user.id);
            incrementPlayerRelationship(ctx, b.userId, a.userId, gameMode, draftMode, isAlly, bWon, user.id);
        }
    }
    ```

15. **Bracket advancement (MTCH-08):** If this is a tournament bracket match, advance the bracket atomically in the same transaction:
    ```
    if (matchResult.isTournamentControlled && matchResult.bracketMatchId !== undefined && matchResult.winnerUserId !== undefined) {
        // Check if bracket advancement already happened (submit_and_advance_bracket may have been called)
        const bracketMatch = ctx.db.BracketMatch.id.find(matchResult.bracketMatchId);
        if (bracketMatch && bracketMatch.winnerTeamId === undefined) {
            // Map winnerUserId to teamId via TournamentParticipant
            const winnerParticipant = [...ctx.db.TournamentParticipant.by_tournament_and_user
                .filter([matchResult.tournamentId!, matchResult.winnerUserId])][0];
            if (winnerParticipant && winnerParticipant.teamGroupId) {
                advanceBracketMatch(ctx, matchResult.bracketMatchId, winnerParticipant.teamGroupId, user.id);
            }
        }
        // If winnerTeamId is already set, bracket was already advanced by submit_and_advance_bracket -- skip
    }
    ```

16. Delete ephemeral records (order matters -- children first per Research Pitfall 8):
    ```
    for (const g of games) { ctx.db.MatchResultGame.delete(g); }
    for (const p of participants) { ctx.db.MatchResultParticipant.delete(p); }
    // Re-read the match result (it may have been updated with mmrProcessedAt)
    const finalResult = ctx.db.MatchResultRecord.id.find(matchResultId);
    if (finalResult) { ctx.db.MatchResultRecord.delete(finalResult); }
    ```

17. Console log: `[MATCH] Match result #${matchResultId} finalized by user #${user.id}. History ID: ${historyRow.id}`

**`process_tournament_mmr` reducer:**

Per D-11 (tournament batch path). Permission: TO/assistant/Moderator/Admin.

Reducer args: `{ tournamentId: t.u32() }`

Implementation:
1. `const { user, tournament } = ensureTournamentAccess(ctx, tournamentId)`
2. Verify tournament is Completed or Cancelled: throw `'Tournament must be Completed or Cancelled to process MMR.'` if `tournament.stage.tag !== 'Completed' && tournament.stage.tag !== 'Cancelled'`
3. Verify tournament counts toward MMR: if `!tournament.countTowardsMmr`, throw `'This tournament does not count toward MMR (countTowardsMmr=false).'`
4. Find all Validated, unprocessed MatchResultRecords for this tournament:
   ```
   const matchResults = [...ctx.db.MatchResultRecord.tournament_id.filter(tournamentId)]
       .filter(mr => mr.status.tag === 'Validated' && mr.mmrProcessedAt === undefined);
   ```
5. If no matches found: `console.log('[MMR] No unprocessed matches for tournament #' + tournamentId); return;`
6. Read EloConfig once: `const config = ctx.db.EloConfigTable.id.find(1)`. Throw if missing.
7. For each match result:
   - Read participants: `[...ctx.db.MatchResultParticipant.match_result_id.filter(mr.id)]`
   - Read games (for gameMode): `[...ctx.db.MatchResultGame.match_result_id.filter(mr.id)]`
   - Determine gameMode from games or lobby
   - Call `processMatchMmr(ctx, mr, participants, gameMode, 0 /* sentinel matchHistoryId */, user.id)`
     MmrHistory rows are inserted with matchHistoryId=0 as sentinel. When finalize_match_result runs later for each match, it writes MatchSessionHistory and back-fills the real matchHistoryId into these MmrHistory rows (see step 11 in finalize_match_result above).
   - Stamp mmrProcessedAt: `ctx.db.MatchResultRecord.id.update({...mr, mmrProcessedAt: ctx.timestamp, ...auditUpdate(ctx, mr, user.id)} as any)`

8. Rebuild leaderboard once after all matches processed: `rebuildLeaderboard(ctx, user.id)`
9. Console log: `[MMR] Processed ${matchResults.length} tournament matches for tournament #${tournamentId}`
