## Decisions Made
- `ensureModerator(ctx)` returns the `user` object directly, not `{ user }` — plan code showed destructuring pattern but actual helper returns user directly; used `const user = ensureModerator(ctx)` throughout
- Admin GC reducers explicitly do NOT self-requeue — prevents admin from inadvertently starting a parallel scheduled chain (Pitfall 6)
- `IDENTITY_TTL_MICROS` computed as `BigInt(90 * 24 * 60 * 60) * 1_000_000n` to avoid any safe integer boundary issues in the microsecond arithmetic
- lobby GC restructure kept all existing GC logic verbatim inside `performLobbyGc` — no behavior changes, only added counters before each `hardDeleteLobby` call and GcResult write in the reducer wrapper
