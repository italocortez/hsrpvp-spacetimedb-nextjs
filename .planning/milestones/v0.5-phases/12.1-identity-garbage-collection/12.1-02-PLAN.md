# Plan 02: Identity GC Reducers

**Goal:** Implement identity GC reducers (scheduled + admin-triggered), wire GcResult into lobby GC, and add post-publish seed automation.

## Requirements Addressed

- **GC-01:** Identity GC scheduled reducer (weekly 90-day TTL sweep)
- **GC-02:** GcResult audit row on every GC run
- **GC-03:** Admin-triggered GC for both identity and lobby
- **GC-04:** Match result orphan audit in hardDeleteLobby

## Tasks

### Task 1: Create identity GC reducer with scheduled + admin + seed reducers

**Files:**
- Create `spacetimedb/src/reducers/identityGc.ts`

**Reducers:**
- `run_identity_gc` (scheduled) — Weekly 90-day TTL sweep with GcResult audit + self-requeue
- `admin_gc_identities` (admin-triggered) — Moderator+-gated, one-shot with GcResult, no self-requeue
- `seed_identity_gc_job` (server-only) — Idempotent bootstrap, skips if IdentityGcJob already has a row

**Shared helper `performIdentityGc`:**
- D-06: Skip guest users entirely
- D-07: Preserve newest identity per user (sort by lastSeenAt desc, keep first)
- D-08: Skip users currently online
- D-11: 90-day TTL for remaining identities
- D-12: Orphaned identity rows (user not found) deleted immediately
- D-05: console.log per deletion with [IDENTITY_GC] prefix

**Constants:**
- `IDENTITY_TTL_MICROS = BigInt(90 * 24 * 60 * 60) * 1_000_000n` — avoids safe integer overflow
- `SEVEN_DAYS_MICROS = BigInt(7 * 24 * 60 * 60 * 1_000_000)` — weekly requeue interval

**Design decisions:**
- Shared `performIdentityGc` helper called by both scheduled and admin reducers (Pitfall 6 avoidance)
- Admin GC reducers do NOT self-requeue — prevents admin from starting parallel scheduled chain
- `ensureModerator(ctx)` returns user directly (not `{ user }`)
- GcResult written unconditionally for admin triggers (confirmation even on no-op), conditionally for scheduled (only on deletions)

### Task 2: Wire GcResult into lobby GC, add admin_gc_lobbies, update exports and post-publish

- Modify `spacetimedb/src/index.ts` — Export all new reducers
- Modify `scripts/post-publish.ts` — Bump step denominators to /6, add Step 6 `seedIdentityGcJob` call

**Lobby GC changes:**

- `run_lobby_gc` now writes `GcResult(gcType='lobby')` on every run (D-14)
- `admin_gc_lobbies` added with `ensureModerator` gate, one-shot (D-15)
- GC-04 audit comment in `hardDeleteLobby` confirming no orphaned MatchResultRecord gaps

## Threat Model

- T-12.1-06: Server identity check in `seed_identity_gc_job` rejects non-server callers
- T-12.1-07: isGuest + isOnline guards + preserve-newest logic prevent active user identity loss
