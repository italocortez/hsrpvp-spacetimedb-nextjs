## Decisions Made
- lastSeenAt bump uses manual audit fields rather than `auditUpdate` helper because `mapping` uses `identity` PK (not `id`), and only `lastSeenAt + lastModified*` change while `createdById/createdDate` are preserved by spread
- GcResult has no indexes — table is small (one row per GC run) and admin reads only via SpacetimeDB dashboard
- durationMs column always stores 0 — `ctx.timestamp` is pinned at reducer invocation start so wall-clock elapsed time cannot be measured within a reducer
