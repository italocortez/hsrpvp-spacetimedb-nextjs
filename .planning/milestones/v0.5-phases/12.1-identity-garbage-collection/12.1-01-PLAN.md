# Plan 01: GC Schema Foundation

**Goal:** Create shared GC audit infrastructure and identity staleness tracking — schema tables that Plan 02 reducers will consume.

## Requirements Addressed

- **GC-01:** GcResult audit table for tracking all GC runs
- **GC-02:** IdentityGcJob scheduled table for weekly GC chain
- **GC-04:** Verify UserPrivate cascade completeness in performUserDeletion

## Tasks

### Task 1: Create GcResult and IdentityGcJob tables, register in schema.ts

**Files:**
- Create `spacetimedb/src/tables/gcResult.ts` — Private GC audit table (D-10): id, gcType, ranAt, itemsScanned, itemsDeleted, durationMs, details + audit columns
- Create `spacetimedb/src/tables/identityGcJob.ts` — Scheduled table with mutable `_runIdentityGcReducer` binding (mirrors LobbyGcJob pattern for circular-dep avoidance)
- Modify `spacetimedb/src/schema.ts` — Import and register GcResult (GC Audit section) and IdentityGcJob (Scheduled Jobs section)

**Patterns:**
- GcResult uses `public: false` — admin reads via dashboard only
- GcResult has no indexes — table is small (one row per GC run)
- IdentityGcJob mirrors LobbyGcJob mutable binding pattern exactly
- gcType discriminator string allows multi-type GC sharing one audit table

### Task 2: Bump lastSeenAt in clientConnected, verify UserPrivate cascade

**Files:**
- Modify `spacetimedb/src/index.ts` — Add `lastSeenAt: ctx.timestamp` bump in clientConnected after isOnline update, before ban check
- Modify `spacetimedb/src/helpers/userDeletionHelper.ts` — Add D-09 audit comment confirming UserPrivate hard-delete cascade completeness

**Design decisions:**
- lastSeenAt bump uses manual audit fields (not auditUpdate helper) — mapping uses identity PK not id, and only lastSeenAt + lastModified* change while createdById/createdDate are preserved by spread
- durationMs column always stores 0 — ctx.timestamp is pinned at reducer invocation start so wall-clock elapsed time cannot be measured within a reducer

## Threat Model

- T-12.1-02: GcResult uses `public: false` — prevents client egress of GC audit data
- T-12.1-03: IdentityGcJob columns contain no sensitive data — scheduled_id and scheduled_at only

## Dependencies

- Requires: Phase 12 (auth hardening) — UserIdentity table with lastSeenAt column, userDeletionHelper cascade chain
- Provides to Plan 02: GcResult table, IdentityGcJob table, setRunIdentityGcReducer binding, live lastSeenAt data
