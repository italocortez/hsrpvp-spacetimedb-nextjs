<objective>
Extend `select_match_account` with a monotonic-upward update hook that runs after the LMA insert: if a `MatchResultRecord` exists for this lobby and the caller has an MRP row, update `accountRatingSnapshot = max(existing_snapshot, newAccount.accountRating)` via composite-PK delete+insert preserving audit columns. The hook is gated by MRP existence (not lobby stage), so it's a no-op during `Waiting` and cleanly handles stand-ins.

Purpose: Preserve the "max across series" fairness rule during `BetweenGames` in best-of-N series — a player who brings a high-rated account for game 1 and swaps to a low-rated one for game 2 still has MMR computed against the high rating. Also handles the reverse case: swapping to a higher-rated account for a later game increases the snapshot.

Output: `accountSelection.ts` with the hook landed in both branches of `select_match_account` (tournament additive + non-tournament replace). `deselect_match_account` is unchanged. Stand-in no-op documented via code comment.
</objective>

```typescript
// D-B-03 (Phase 12.3): monotonic-upward snapshot update for BetweenGames account swaps.
// Gated by MRP existence, not lobby stage:
//   - Waiting: no MatchResultRecord yet (created at draftClassic.ts:178 inside start_draft),
//     lookup returns empty -> no-op.
//   - BetweenGames: MRR exists, MRP exists -> update with max rule.
//   - Stand-in joining after start_draft: LMA row exists (seeded on join) but no MRP row for
//     them (MRP only inserted at start_draft:204) -> short-circuit at `if (!mrp) return;`.
//     Stand-ins are intentionally excluded from MMR attribution (D-B-05, D-B-06); mid-series
//     stand-in MMR is a deferred concern.
const mr = [...ctx.db.MatchResultRecord.lobby_id.filter(lobbyId)][0];
if (!mr) return;
const existingMrp = [...ctx.db.MatchResultParticipant.by_result_and_user.filter([mr.id, user.id])][0];
if (!existingMrp) return;
const freshAccount = ctx.db.HsrAccount.id.find(hsrAccountId);
if (!freshAccount) return;
const newSnapshot = Math.max(existingMrp.accountRatingSnapshot, freshAccount.accountRating);
if (newSnapshot === existingMrp.accountRatingSnapshot) return;
ctx.db.MatchResultParticipant.delete(existingMrp);
ctx.db.MatchResultParticipant.insert({
    ...existingMrp,
    accountRatingSnapshot: newSnapshot,
    ...auditUpdate(ctx, existingMrp, user.id),
} as any);
```
