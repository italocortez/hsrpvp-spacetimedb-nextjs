    **Interface: BracketMatchDescriptor**
    Define this interface at the top of the file. It represents a match to be created:
    ```typescript
    export interface BracketMatchDescriptor {
        roundNumber: number;
        matchNumber: number;
        bracketSide: string;        // 'Winners' | 'Losers' | 'GrandFinals' | 'ThirdPlace' | 'Group'
        groupId?: number;
        participant1Id?: number;    // TournamentTeam.id
        participant2Id?: number;    // TournamentTeam.id
        bestOf: number;
        winnerAdvantage: number;
        winnerId?: number;          // Pre-set for BYE matches
        // Position-based references for FK wiring (resolved to real IDs by reducer):
        positionKey: string;        // Unique key like "W-R1-M1" (bracket side initial + round + match)
        nextWinnerRef?: string;     // positionKey of match winner advances to
        nextLoserRef?: string;      // positionKey of match loser goes to (double elim only)
        isParticipant1Slot?: boolean; // true = place in slot 1 of next match, false = slot 2
    }
    ```

    **Function 1: `foldSeeding(bracketSize: number): number[][]`**
    Standard fold/mirror seeding algorithm. Input: bracketSize (power of 2). Output: array of [seed1, seed2] matchups.
    Algorithm: Start with [[1,2]]. Double bracket size each iteration. For each existing [a,b], create two new matchups: [a, nextSize+1-a] and [b, nextSize+1-b]. Continue until currentSize reaches bracketSize.
    Example: bracketSize=8 produces [[1,8],[4,5],[2,7],[3,6]].

    **Function 2: `generateSingleElimBracket(teamIds: number[], bestOf: number, has3rdPlaceMatch: boolean): BracketMatchDescriptor[]`**
    - teamIds is sorted by seed (index 0 = seed 1). Length can be any number >= 2.
    - Calculate bracketSize = smallest power of 2 >= teamIds.length
    - Generate fold seeding for bracketSize
    - Map seed numbers to teamIds. Seeds > teamIds.length become BYE (no participant).
    - Determine total rounds = log2(bracketSize)
    - Create descriptors for all matches:
      - Round 1: One match per matchup. Matchup with one BYE => set winnerId to the non-BYE team, pre-advance.
      - Rounds 2..totalRounds: matches = bracketSize / (2^round). Wire nextWinnerRef from previous round.
      - Position keys use format "W-R{round}-M{match}" (W for Winners).
      - Final match: roundNumber = totalRounds, matchNumber = 1
    - For nextWinnerRef wiring: R1-M1 and R1-M2 both point to R2-M1. R1-M3 and R1-M4 point to R2-M2. Pattern: R{n}-M{m} points to R{n+1}-M{ceil(m/2)}. The isParticipant1Slot flag: odd matchNumber -> slot 1, even -> slot 2.
    - If has3rdPlaceMatch and totalRounds >= 2: Add one extra descriptor with bracketSide='ThirdPlace', roundNumber=totalRounds, matchNumber=1. The two semifinal matches (R{totalRounds-1}-M1 and R{totalRounds-1}-M2) get nextLoserRef pointing to this ThirdPlace match.
    - For BYE matches (one participant null): set winnerId = the present teamId. The reducer handles auto-advancing.

    **Function 3: `generateDoubleElimBracket(teamIds: number[], bestOf: number, winnerAdvantage: number, has3rdPlaceMatch: boolean): BracketMatchDescriptor[]`**
    - Same fold seeding for winners bracket as single elim.
    - Winners bracket: same structure as single elim (without 3rd place).
    - Losers bracket structure: alternating minor (internal LB) and major (feed-in from WB) rounds.
      - For bracketSize N, winners bracket has log2(N) rounds.
      - Losers bracket has (log2(N) - 1) * 2 rounds (alternating minor/major).
      - Position keys: "L-R{round}-M{match}" for losers.
    - CRITICAL: Losers from winners bracket feed into losers bracket in CROSSED order to minimize rematches. WR1 losers from top half -> LR1 bottom, and vice versa.
    - Losers bracket wiring:
      - LR1 (minor): pairs of WR1 losers play each other. matches = bracketSize/4.
      - LR2 (major): LR1 winners vs WR2 losers (crossed). matches = bracketSize/4.
      - LR3 (minor): LR2 winners play each other. matches = bracketSize/8.
      - LR4 (major): LR3 winners vs WR3 losers (crossed). matches = bracketSize/8.
      - Continue alternating until 1 match remains (LB finals).
    - WB losers feed into losers bracket via nextLoserRef on winners bracket matches:
      - WR1 matches: nextLoserRef -> LR1 matches (crossed order)
      - WR2 matches: nextLoserRef -> LR2 matches (crossed order)
      - WR{n} matches: nextLoserRef -> LR{2*(n-1)} matches (major rounds, crossed)
    - Grand Finals: 1 match, bracketSide='GrandFinals', participants = WB final winner vs LB final winner. winnerAdvantage set from parameter.
    - 3rd Place match (if has3rdPlaceMatch): bracketSide='ThirdPlace'. Semifinal losers from WB (WB semifinal matches nextLoserRef -> ThirdPlace match).
    - BYE handling same as single elim.

    **Function 4: `circleSchedule(teamIds: number[]): [number, number][][]`**
    Round-robin circle method. Input: array of teamIds. Output: array of rounds, each containing [teamId1, teamId2] matchups.
    Algorithm: If odd count, add -1 sentinel (BYE). Fix position 0, rotate rest. n-1 rounds for n teams. Pair teams[i] with teams[n-1-i]. Skip pairs containing -1.

    **Function 5: `snakeSeedIntoGroups(sortedTeamIds: number[], groupCount: number): Map<number, number[]>`**
    Snake/serpentine distribution. Input: sorted teamIds (index 0 = seed 1), group count. Output: Map of groupId (0-based) -> teamId arrays.
    Algorithm: Alternate direction each "row". Row 0: 0,1,2,...,groupCount-1. Row 1: groupCount-1,...,1,0. Row 2: 0,1,2,...  Continue until all teams assigned.

    **Function 6: `generateGroupPhaseBracket(teamIds: number[], groupSize: number, bestOf: number, groupAssignmentMode: string): { matches: BracketMatchDescriptor[], groupAssignments: Map<number, number[]> }`**
    - Calculate groupCount = Math.ceil(teamIds.length / groupSize). Distribute remainder (some groups get groupSize+1 members).
    - If groupAssignmentMode === 'Auto': use snakeSeedIntoGroups to distribute.
    - If 'Manual': still assign sequentially (TO can swap seeds to change groups).
    - For each group: call circleSchedule to generate round-robin matchups.
    - Create BracketMatchDescriptor for each matchup: bracketSide='Group', groupId=group index, roundNumber=round index+1, matchNumber=sequential within group.
    - Position keys: "G{groupId}-R{round}-M{match}"
    - No nextWinnerRef/nextLoserRef for group matches (standings determine advancement, not FK wiring).
    - Return both match descriptors and group assignments (for GroupStanding row creation by reducer).

    **Function 7: `generateHybridBracket(teamIds: number[], groupSize: number, bestOf: number, groupAssignmentMode: string, elimFormat: 'single' | 'double', winnerAdvantage: number, has3rdPlaceMatch: boolean, groupAdvanceCount: number): { groupMatches: BracketMatchDescriptor[], elimMatches: BracketMatchDescriptor[], groupAssignments: Map<number, number[]> }`**
    - Generate group phase using generateGroupPhaseBracket.
    - Calculate how many teams advance: groupCount * groupAdvanceCount.
    - Generate elimination bracket structure using generateSingleElimBracket or generateDoubleElimBracket with EMPTY teamIds array of the correct size (advancingCount phantom placeholders). The participant slots in elimination matches are all undefined -- they get filled when groups complete.
    - Adjust elimination match position keys to avoid collisions with group phase keys (prefix "E-" for elimination).
    - Return group matches, elimination matches (with empty slots), and group assignments.

    All functions are pure (no ctx, no DB access, no side effects). Export all functions.

    **Two-pass FK wiring helper (internal to this file):**
    ```typescript
    function insertBracketMatches(
        ctx: any,
        tournament: any,
        userId: number,
        descriptors: BracketMatchDescriptor[],
    ): void {
        // Pass 1: Insert all matches with null FKs, build positionKey -> insertedId map
        const idMap = new Map<string, number>();
        for (const desc of descriptors) {
            const row = ctx.db.BracketMatch.insert({
                id: 0,
                tournamentId: tournament.id,
                roundNumber: desc.roundNumber,
                matchNumber: desc.matchNumber,
                bracketSide: { tag: desc.bracketSide, value: {} } as any,
                groupId: desc.groupId,
                participant1Id: desc.participant1Id,
                participant2Id: desc.participant2Id,
                nextWinnerMatchId: undefined,
                nextLoserMatchId: undefined,
                bestOf: desc.bestOf,
                gameMode: tournament.defaultGameMode,
                winnerAdvantage: desc.winnerAdvantage,
                scheduledAt: undefined,
                lobbyId: undefined,
                checkInRequired: tournament.checkInEnabled,
                winnerId: desc.winnerId,
                resultStatus: desc.winnerId
                    ? { tag: 'Validated', value: {} } as any
                    : { tag: 'Pending', value: {} } as any,
                ...auditInsert(ctx, userId),
            } as any);
            idMap.set(desc.positionKey, row.id);
        }

        // Pass 2: Update FK links using the positionKey -> id map
        for (const desc of descriptors) {
            if (desc.nextWinnerRef || desc.nextLoserRef) {
                const matchId = idMap.get(desc.positionKey);
                if (!matchId) continue;
                const row = ctx.db.BracketMatch.id.find(matchId);
                if (!row) continue;

                const nextWinnerId = desc.nextWinnerRef ? idMap.get(desc.nextWinnerRef) : undefined;
                const nextLoserId = desc.nextLoserRef ? idMap.get(desc.nextLoserRef) : undefined;

                if (nextWinnerId || nextLoserId) {
                    ctx.db.BracketMatch.id.update({
                        ...row,
                        nextWinnerMatchId: nextWinnerId ?? row.nextWinnerMatchId,
                        nextLoserMatchId: nextLoserId ?? row.nextLoserMatchId,
                        lastModifiedById: userId,
                        lastModifiedDate: ctx.timestamp,
                    } as any);
                }
            }
        }

        // Pass 3: Auto-advance BYE matches
        // BYE matches have winnerId set but may need to place the winner in the next match
        for (const desc of descriptors) {
            if (desc.winnerId && desc.nextWinnerRef) {
                const matchId = idMap.get(desc.positionKey);
                const nextMatchId = idMap.get(desc.nextWinnerRef);
                if (!matchId || !nextMatchId) continue;

                const nextMatch = ctx.db.BracketMatch.id.find(nextMatchId);
                if (!nextMatch) continue;

                // Place BYE winner in the appropriate slot of the next match
                if (!nextMatch.participant1Id) {
                    ctx.db.BracketMatch.id.update({
                        ...nextMatch,
                        participant1Id: desc.winnerId,
                        lastModifiedById: userId,
                        lastModifiedDate: ctx.timestamp,
                    } as any);
                } else if (!nextMatch.participant2Id) {
                    ctx.db.BracketMatch.id.update({
                        ...nextMatch,
                        participant2Id: desc.winnerId,
                        lastModifiedById: userId,
                        lastModifiedDate: ctx.timestamp,
                    } as any);
                }
            }
        }
    }
    ```
