- 2 test failures in `anonymous-labels.test.ts` are pre-existing state-bleed: `beforeAll` for `broadcast_cursor` describe block runs after `write-time anonymous label gate` tests which create/cleanup lobbies inline without afterAll guards. Zero logic was changed by this plan — only `export const` prefixes were added to view declarations.
- SDK 2.1.0 changelog audit: no 2.0.3-specific workarounds found in app code. `isReady` in GameDataProvider is application-level data-loaded checking. `subscriptionBuilder` is unchanged stable API.
