# Phase 10.4: Account Selection Per Match — Verification Report

**Phase Goal:** Players choose which enrolled HSR account(s) to use per match. Tournament setting controls whether 1 or multiple accounts are allowed per player per match (default: 1). Account selection happens at lobby join for tournament lobbies and is changeable between games in best-of-N series. Drop redundant `TournamentEnrolled.hsrAccountId`. Stand-ins select account on lobby join (same flow).

## Root Cause Analysis

The SUMMARY for Plan 01 documented a deviation: "Skipped schema.ts reducer import — project does NOT use explicit reducer imports in schema.ts — all reducer files are auto-discovered via TypeScript's `src/**/*` glob." This reasoning was correct for schema.ts but missed the real entry point.

The build chain is: `index.ts` (entry) → explicitly exports from each reducer file → bundled into `bundle.js`. This is confirmed by `index.ts` lines 9-48, which explicitly export every reducer. The `tsconfig.json` `"include": ["src/**/*"]` controls what TypeScript _type-checks_, not what the bundler includes.

All other Phase 10.4 work is complete and deployed: schema changes, lifecycle wiring, ownership validation refactor, start_draft gate, views, docs, and bindings for schema changes. The single missing action is one `export` line in `index.ts`.

## Gaps Summary

One gap blocks full goal achievement. The `select_match_account` and `deselect_match_account` reducers are fully implemented in source (`accountSelection.ts`) with correct logic for both tournament and non-tournament paths, stage guards, and maxAccountsPerPlayer enforcement. However, the file was never wired to the bundler's entry point (`index.ts`). As a result, the compiled `bundle.js` does not contain these reducers, the module published to maincloud does not expose them, and no client binding files were generated.

Fix: add one export line to `index.ts` and re-publish.

All other must-haves are verified: LobbyMemberAccount table, schema changes (Tournament.maxAccountsPerPlayer, TournamentEnrolled.hsrAccountId removal, HsrAccount/HsrAccountCharacter privacy), lifecycle wiring, deletion guards, ownership validation refactor, start_draft enforcement, 3 new views, anonymous mode fix, and all architecture/contract docs.
